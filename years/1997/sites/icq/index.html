The Internet's Instant Messaging Sensation · 1997

ICQ — I Seek You

A revolutionary, user-friendly Internet tool that informs you who's online at any time and enables you to contact them at will.

Features (period pitch):

  • Buddy list — see when friends log on
  • Instant messages & chat
  • File send (when the modem allows)
  • Download the Windows client (not a full web app — yet)

Founded by Mirabilis (Israel). Acquired by AOL in 1998. Late-1997 capture reference: Wayback icq.com Dec 1997.

 		Also on the 1997 net:
  • Internet Explorer 4.0
  • PointCast (push)
  • GeoCities — 1M homesteaders
  • Slashdot

ICQ is a download, not a browser page — that's the point. Instant messaging lived beside the open Web.
