Microsoft Internet Explorer 4.0

September 22, 1997— Internet Explorer 4.0 ships into a browser war already at fever pitch. Microsoft’s launch stunt (a giant letter “e” planted on Netscape’s lawn) is as much headline as the product: Active Desktop, Dynamic HTML, Channels, and tighter Windows 95 integration.

What IE4 pushes this year
  • Channels— push-style content rails (exhibit: PointCast/ dirbar Channels)
  • Active Desktop— HTML on the Windows desktop (often hated by IT)
  • DHTML + CSS— more motion than Netscape 3 pages, still mostly tables in the wild
  • 56k era— dial-up is still the norm; “broadband” is a distant office perk

Netscape Communicator 4 still leads many market-share charts late in the year, but IE4 is the product Microsoft wants on every OEM desktop. Corporate “best viewed with” badges start to pick sides.
