About 2009

2009 is when the social web goes mainstream and smartphone apps become daily habit. Facebook ships the Like button, passes MySpace, buys FriendFeed, and kills Beacon. FarmVille invents mass social-game spam. The iPhone 3GS + App Store (50k+ apps, 1B+ downloads) make apps everyday. Bing rebrands Microsoft search. Windows 7 ships in October. Desktop Web 2.0 is still how most people live — phones add daily apps, they do not erase the laptop.

Scale (Internet Live Stats, June class): 238,027,855 websites (+38% from 2008’s 172,338,726) · ~1.77B internet users · Pingdom late-2009 class also ~1.73B users / ~234M sites Dec. Shell here: Windows XP + IE 8 mass path; Windows 7 optional from Oct 22; Chrome is a product room, not forced sole shell.

How a day felt

Boot XP · open IE 8 (or Firefox / Chrome) · Facebook (Like everything) · Twitter if you’re Oprah-curious · YouTube after dinner · Gmail always on. Friends with a 3GS talk about copy/paste and video. Play FarmVille until 2 a.m. Try Bing for a week. Austin kids check in on Foursquare. Europe still has Spotify invites. Most of the world still fat laptop — but the phone finally runs apps every day.
