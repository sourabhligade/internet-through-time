About Windows 8.1

October 17, 2013 general availability. Public beta at Build (June). Free upgrade for many Windows 8 users. Narrative: fix the Start experience after 2012 criticism — while Start screen remains part of the product.

Museum shell default remains dual-honest: Win7 residual early–mid · 8.1 as late product room. IE ships with the platform; Chrome is the desktop browser-war story.
