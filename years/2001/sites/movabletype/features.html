Movable Type · Features

Features · late 2001

Six Apart ships Movable Type as a professional weblog toolkit (Oct 2001 era). Install on your own host, own your templates, publish static HTML that survives PHP fads.

  • Multiple blogs, one install
  • Full template customization
  • Static HTML output (speed + reliability)
  • RSS out of the box (0.91; 1.0 templates appear)
  • weblogs.com XML-RPC ping
  • Greymatter import path
  • Export for backup

TrackBack peer-ping becomes the 2002 blogosphere differentiator — 2001 is professionalization: leave free hosted tools when you outgrow them. Compare Blogger (hosted ease) vs MT (own the files).
