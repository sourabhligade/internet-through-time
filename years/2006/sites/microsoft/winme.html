Windows Me

Retail: September 14, 2001. Marketed for home users: System Restore, Movie Maker, updated media toys, Internet Explorer 6 built in. Still DOS-descended under the hood — the last of that line before XP.

Period reception is mixed (stability jokes write themselves), but the desktop aesthetic stays in the Win98 family: gray bevels, Start button, tray clock.
