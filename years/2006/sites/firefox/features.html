Features — Firefox 1.0

Mozilla Foundation press (November 9, 2004): a more robust, user-friendly, trustworthy web experience — open source, free, community-driven.

  • Pop-up Blocking— integrated blocker; users, not websites, decide when to see pop-ups
  • Online Fraud Protection— phishing (password theft) and spoofing (fake trusted sites); clear identity of secure sites
  • Faster, easier search— toolbar integrations (Google, Yahoo!, eBay, Amazon, Dictionary.com, Creative Commons…)
  • Tabbed Browsing— many pages in one window; open links in background tabs
  • Live Bookmarks— glance at RSS news and blog headlines from the bookmark menu
  • Extensions— 100+ add-ons early; toolbars and themes make Firefox customizable
  • Easy Migration— import bookmarks, passwords, cookies, and other data from Internet Explorer
  • Find as you type · download manager · privacy tools of the era · multi-platform (Win / Mac / Linux)

Platforms: Windows · Mac OS X · Linux. Honesty: IE 6 on XP is still the mass default install base — Firefox is the rising open choice, not yet the majority Windows shell in 2004.
