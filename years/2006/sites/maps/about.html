Google Maps in 2006

Continuity year: Maps launched for desktop February 8, 2005. The Ajax essay (Jesse James Garrett) is Feb 18, 2005. HousingMaps-class mashups and the official Maps API (June 2005) are already last year’s story.

In 2006 people simply use Maps: drag, zoom, Local Search, directions, embedded mashups everywhere. Developer cloud arrives via AWS; web office via Google Docs — Maps remains the Ajax poster child people already know.

Hard ban: Street View is not 2006 (debut May 29, 2007). No pegman as default UI. No live tile CDN in this museum — status-line theater only.

Local Search grammar: What (e.g. pizza) · Where (e.g. Portland, OR) · Directions start/end · JavaScript required notice.
