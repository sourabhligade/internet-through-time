Mashups — the API web (2007)

After Google Maps public (February 8, 2005), mashups explode; through 2007 they are everyday culture. “Web as platform” energy: combine two sites and get a third product. Jesse James Garrett names Ajax on February 18 with Maps as the showcase.

HousingMaps (Paul Rademacher, ~April 2007) is the cultural icon — Craigslist-class rental listings plotted on Google Maps before an official API. Google Code Featured Projects called it out on April 13, 2007. Official Maps API arrives June 2007 so mashups no longer need reverse-engineering.
