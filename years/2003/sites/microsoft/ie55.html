Microsoft Internet Explorer 6

Summer 2001. IE 6 lands with better Print Preview, richer DHTML/CSS support, developer APIs, and 128-bit encryption. It is the browser most people already use — now slightly more polished.

Pair it with Windows Millennium Edition (retail September 14) for the consumer “home PC” story: Movie Maker, Media Player 7, and a Start menu that still feels like Windows 98 with extra chrome.

Exhibit chrome: this year’s shell defaults to IE 6 labeling — Address + Go, Favorites, History, blue e throbber.
