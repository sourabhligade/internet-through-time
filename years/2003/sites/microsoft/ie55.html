Microsoft Internet Explorer 6

2003 — peak monopoly years. Internet Explorer 6 shipped August 27, 2001 with Windows XP (retail October 25, 2001). By 2003 most home and office machines already run it.

Print Preview, richer DHTML/CSS, image toolbar, media bar, 128-bit encryption. Competitors (Netscape 7, early Mozilla / Phoenix) exist, but IE 6 is the web’s default surface.

Pair it with Windows XP — Luna Start button, taskbar, and the blue e in the corner. Windows Me and 98 SE are legacy pages for older PCs still in closets.

This year’s exhibit shell: IE 6 labeling — Address + Go, Favorites, History, XP taskbar.
