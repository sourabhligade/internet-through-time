# 1995 Immersion

Windows 95 desktop · Netscape Navigator 2.0 · late 1995 commercial Web.

## Sites

| Path | Site |
|------|------|
| `sites/yahoo/` | Yahoo! at **yahoo.com** |
| `sites/amazon/` | Amazon.com books + cart |
| `sites/auctionweb/` | AuctionWeb (early eBay) + bids |
| `sites/geocities/` | GeoCities neighborhoods |
| `sites/altavista/` | AltaVista full-text search |
| `sites/cnn/` | CNN Interactive sample |

## Run

```bash
python3 -m http.server 8080
```

Open http://localhost:8080/years/1995/
