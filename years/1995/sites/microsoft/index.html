Microsoft Internet Explorer

Internet Explorer 1.0

Ships with Microsoft Plus! for Windows 95 (Internet Jumpstart Kit), August 1995. Based on Spyglass Mosaic. Small (~1 MB) and limited vs Netscape 2.0.

  • Windows 95
  • Basic HTML
  • Free with Plus!

Compare: Netscape Navigator 2.0
