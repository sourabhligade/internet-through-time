Firefox 1.0

Rediscover the web. The browser, reloaded.

November 9, 2004 — Mozilla Foundation releases the highly anticipated Firefox 1.0 for Windows, Mac OS X, and Linux. Open-source community development.

OSS trail: 1999 SourceForge → Firefox 1.0 → 2008 GitHub

Free Download   Features · What's New · NYT ad (Dec 15)

  • Tabbed browsing — many pages in one window; open links in the background
  • Popup blocking — you decide when ads interrupt (built-in)
  • Online fraud protection — phishing & spoofing identity cues
  • Smarter search — Google and other engines in the toolbar
  • Live Bookmarks — RSS headlines in the bookmark menu
  • Easy switch — import Favorites, passwords, cookies from Internet Explorer
  • Extensions & themes · ~4.5 MB Windows download class (period PR)

Browser honesty: Internet Explorer 6 on Windows XP is still the mass default (peak IE share ~90–95% class). Firefox is the rising open choice — not yet “everyone’s browser.”
