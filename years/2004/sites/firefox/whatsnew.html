What's New in 1.0

First “1.0” product brand after Mozilla · Phoenix · Firebird lineage (Firebird name conflict with the database project — history note). November 9, 2004 is the hinge for “browser choice” press. Mozilla milestones: tabbed browsing · popup blocking · fraud/phishing protection · open-source community.

  • Stable release framed for everyday browsing, not only early adopters
  • Security focus vs IE6-era malware / ActiveX fear in press culture
  • Tabbed browsing and popup blocking as default consumer pitch
  • Live Bookmarks — RSS headlines in the bookmark menu
  • Community marketing: NYT two-page ad Dec 15, 2004 (thousands of donor names)
  • Import path from Internet Explorer so switching is not a full wipe
  • Extensions & themes culture starts — still early vs later Firefox eras

Browser honesty: Windows mass default remains IE 6 on XP (period counters ~90–95% class — Cybercultural). Firefox is the rising choice, not this year’s default shell.
