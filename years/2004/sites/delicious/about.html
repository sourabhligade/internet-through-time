About del.icio.us

del.icio.us is social bookmarking: save links, tag them, and see what the crowd tags. Joshua Schachter lineage. Same folksonomy moment as Flickr photo tags — users invent the index instead of a librarian’s taxonomy.

2004 year-end shout-out (Cybercultural): even as a geeky app, del.icio.us showed community benefits — a recommendation engine for the blogosphere and a rare successful topic map via tags.

Web 2.0 hinge companions: Flickr · Bloglines · Web 2.0 Conference · Technorati.

Yahoo acquisition of del.icio.us is a later story — not required ownership framing for calendar 2004. No real accounts · no remote API · bookmarks listed on the home page are exhibit samples.
