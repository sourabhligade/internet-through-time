A semantic personal publishing platform with a focus on aesthetics, web standards, and usability.

May 27, 2003— v0.7 public release by Matt Mullenweg & Mike Little. Fork of b2/cafelog (~2,000 blogs May 2003). PHP + MySQL · self-hosted (not Blogger-hosted). Named the new official branch of b2.

Get WordPress
Download 0.7 · Install theater · Dashboard · View blog

Contrast: Blogger (Google-owned from Feb 2003) is hosted; Movable Type remains the pro package; WordPress is the open self-host path.

Origin note: Mullenweg’s Jan 2003 “Blogging Software Dilemma” post led to the b2 fork that became WordPress.
