Windows Internet Explorer 7

October 18, 2007 — IE 7 public release for Windows XP SP2 (and Vista). First major Internet Explorer update since IE 6 (2001).

What people notice:

  • Tabbed browsing for the mass IE audience
  • Phishing filter · tighter security story after IE6 years
  • RSS feed discovery in the browser chrome
  • Still not Chrome (2008) · Firefox already has tabs for cool bloggers

Museum shell honesty: This immersion’s default remains Windows XP + IE 6 for most of 2007. IE 7 is a late-year download / product story — not a forced shell upgrade. Windows Vista RTM is Nov 8, 2007; retail mass GA is Jan 30, 2007 — banned as default OS here.
