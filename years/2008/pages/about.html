About 2008

★ One-thing: open a GitHub issue (itt08-github). App Store · Chrome · G1 stay leftover mass, not the chip.

2008 is when the phone becomes a platform and the browser is reinvented again. The App Store ships with iPhone 3G (native apps, not Safari-only). Google Chrome launches as a Windows beta built for web apps. Android reaches consumers as the T-Mobile G1. Hulu goes public; Netflix streaming densifies; Firefox 3 peaks indie browser culture. Desktop Web 2.0 is still how most people live — gatekeepers begin, they do not finish.

Scale (Internet Live Stats, June class): 172,338,726 websites (+41% from 2007’s 121,892,559) · users 1,571,601,630 · chart birthmark Dropbox. Netcraft January 2008 hostnames 155,583,825 · December 2008 186,727,854 — contemporaneous headlines, labeled January/December, never June. Live Netcraft pages [failed-final]. Shell here: Windows XP + IE 7 mass default; Chrome is a late-year product story, not forced sole shell.

How a day felt

Boot XP · open IE 7 (or Firefox if you’re a blogger) · Digg / Facebook · Flash YouTube · open Gmail. From March: free network TV on Hulu with ads. From July: friends with iPhones talk about apps — free games, utilities, “there’s an app for that” seed culture. September: the Chrome comic leaks · try the Windows beta · multi-process tabs that don’t kill everything. Late year: if you’re on T-Mobile, the G1 is the first Android — slide keyboard, Market, “with Google.” Most of the world still lives on a fat laptop. Spotify is Europe-only invite lore — not US public.
