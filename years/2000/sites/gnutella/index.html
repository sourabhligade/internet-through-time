Gnutella

On March 14, 2000, Nullsoft developers (Justin Frankel / Tom Pepper) released Gnutella — a decentralized peer-to-peer protocol — without AOL’s approval. AOL pulled it quickly; the idea escaped into forks and clients.

Contrast with Napster’s centralized index. Educational UI only — no real file sharing from this page.
