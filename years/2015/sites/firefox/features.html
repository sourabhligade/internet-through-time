Features — Firefox 1.0

Mozilla Foundation pitch (Nov 9, 2004 press lineage): faster, safer, more open.

  • Tabbed browsing — multiple sites in one window
  • Built-in popup blocker — you decide when ads interrupt
  • Phishing / spoofing protection — safer surfing pitch of the era
  • Search bar integrations — search without the portal start page
  • Import bookmarks, passwords, cookies from other browsers
  • Live bookmarks (RSS) · extensions / themes ecosystem (early)
  • Find as you type · download manager · privacy tools of the era

Platforms: Windows · Mac OS X · Linux. Honesty: IE 6 on XP is still the mass default install base — Firefox is the rising open choice, not yet the majority shell in this museum year.
