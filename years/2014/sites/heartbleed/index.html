The Heartbleed Bug

CVE-2014-0160 · public 7 April 2014 · OpenSSL 1.0.1g released the same day.

A flaw in the TLS heartbeat extension (RFC 6520) lets a remote attacker read process memory in 64 kilobyte chunks — cookies, passwords, even private keys. Affected: OpenSSL 1.0.1 through 1.0.1f. The 1.0.0 and 0.9.8 branches are not vulnerable. Duplicate CVE-2014-0346 should not be used.
