About the Netscape FishCam

The camera sits in a tank at Netscape. The Web server publishes the latest still. There is no streaming player — only a GIF or JPEG and the Reload button.

In 1994 that is enough to feel like the network is alive.

« FishCam · Netscape · Home

The FishCam is not a movie file. It is a still image that changes when the server updates it — proof that the Web can feel “live” even on a 14.4 modem if you are patient.
