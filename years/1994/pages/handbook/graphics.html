Graphical elements

  • Blue underlined text — a hyperlink you haven't visited
  • Purple underlined text — a hyperlink you have visited
  • Images with colored borders — clickable pictures
  • Broken image icon — the picture file couldn't be loaded
  • Horizontal rules — section dividers

Turn images off if pages load too slowly; you can still follow text links.
