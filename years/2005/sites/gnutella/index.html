Gnutella — Decentralized File Sharing Home

A peer-to-peer protocol with no central Napster-style index — any file type, many clients.

Gnutella is not a single app — BearShare and later LimeWire-class clients popularize the mesh.

For music culture, it is the 'what comes after Napster' answer that is harder to shut down as one company.

Highlights
  • March 2000 Nullsoft release; AOL pulls it; protocol lives on
  • Queries flood a mesh of peers; hits return direct downloads
  • Contrast: Napster's central directory vs Gnutella's protocol openness
  • Bandwidth, fakes, and legal risk sit on the user
