Google Maps + Ajax (2005)

February 8, 2005 — Google Maps launches for desktop (Google Blog: help people “get from point A to point B”). Drag the map, zoom, Local Search — not a static image map.

February 18, 2005 — Jesse James Garrett / Adaptive Path essay names Ajax (Asynchronous JavaScript + XML). Maps (with Gmail) is the poster child for app-like web pages without full reloads.

~April 2005 — mashups before the official API: HousingMaps (Paul Rademacher) plots Craigslist-class housing on Maps by reverse-engineering the JS — the cultural icon of the mashup web.

June 2005 — Google publishes the official Maps API so developers can embed maps without hacking. Mashup culture goes mainstream after HousingMaps and peers proved demand.

Also in 2005: Google Earth lands a few months after Maps; Portland Transit Trip Planner appears by December. Street View is not 2005 (debut May 29, 2007) — do not expect it here.

Local Search grammar from period captures: What (e.g. pizza) · Where (e.g. Poughkeepsie, NY) · Directions start/end · JavaScript required notice.

Honesty: Controls update the status line only — no live GIS tiles in this browser.
