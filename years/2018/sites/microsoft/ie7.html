Windows Internet Explorer 7

October 18, 2007 — IE 7 public release for Windows XP SP2 (and Vista). First major Internet Explorer update since IE 6 (2001).

What people notice:

  • Tabbed browsing for the mass IE audience
  • Phishing filter · tighter security story after IE6 years
  • RSS feed discovery in the browser chrome
  • Still not Chrome (2010) · Firefox already has tabs for cool bloggers
