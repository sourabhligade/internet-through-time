# 3× popular websites — flow map (1994–2015)

**Date:** 2026-08-18  
**What this is:** Three extra **websites** per year, chosen by **that year’s popularity**. Leftover — **not** the chip.  
**Key:** `ittYY-pop-<slug>` · empty field never writes.  
**Spec:** `scripts/popular-3x-sites.json` · rooms: `years/YYYY/sites/<slug>/index.html`

```
Hub → year → Starting Point (star unchanged)
                │
                ├─ Guided 6 / official 10   (locked)
                │
                └─ Also popular this year (3× leftover)
                     A → type + go → ittYY-pop-A
                     B → type + go → ittYY-pop-B
                     C → type + go → ittYY-pop-C
```

Star / guided 6 / Year menu do **not** change.
