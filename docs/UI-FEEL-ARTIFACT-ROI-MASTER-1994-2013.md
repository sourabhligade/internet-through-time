### 1.4 Wayback Machine — harvest cookbook (every asset)

```text
1. Target URL + year window
   https://web.archive.org/web/YYYYMM*/https://example.com/

2. List captures
   https://web.archive.org/web/*/https://example.com/*

3. CDX for assets
   https://web.archive.org/cdx/search/cdx?url=example.com/images/*&from=YYYY&to=YYYY&output=json&filter=statuscode:200&filter=mimetype:image/gif

4. Download with image rewrite
   https://web.archive.org/web/{timestamp}im_/{original-url}
   or id_ for raw

5. Validate
   file logo.gif   # must be GIF/JPEG/PNG, not HTML error page
   identify logo.gif  # optional ImageMagick

6. Install
   assets/period/YYYY/brand/logo-wa.gif
   keep logo-recon.gif if replacing RECON

7. Log
   docs/references/YYYY/CAPTURE-LOG.md
   assets/period/YYYY/ASSETS.md (or year ASSETS)

8. Wire HTML + dimensions + authenticity note

9. Gate
   year e2e + optional authenticity script
```

**Known good patterns already in repo:** HoTMaiL 1997, Yahoo banners, Space Jam live planets, Google logos, XP Start crops — see [`UI-EXACT-SOURCES.md`](references/UI-EXACT-SOURCES.md).

# Part III — ROI framework (how to prioritize)

## 3.1 Score every goal (1–5)

| Factor | 5 = best |
|--------|----------|
| **Visitor impact** | First 30 seconds of year (home, P0 product) |
| **Period signal** | Unmistakably *that year* (Siri, Vine, Timeline, Chrome) |
| **Feasibility** | WA exists / RECON honest / static-friendly |
| **Reuse** | Helps multiple years or modules |
| **Gate risk** | Low e2e break risk |

**ROI score** ≈ (impact × period × feasibility × reuse) / effort.

## 3.2 Work types (do in this order within a year)

| Order | Type | Example | Typical effort |
|------:|------|---------|----------------|
| 1 | **Feel chrome** | Phone shell, client nav, status without keys | Hours |
| 2 | **REAL multi-step flow** | Hold Vine → post → feed | Hours |
| 3 | **Signature WA pixels** | Logo / hero GIF from CDX | 0.5–2 days |
| 4 | **Continuity soft honesty** | Amazon freeze strip + trail links | Hours |
| 5 | **Forest scrub** | Year-voice on residual rooms | Days |
| 6 | **e2e harden** | Soft `if(count)` → hard asserts | Hours |
| 7 | **Optional forever** | Perfect stills after failed harvest | Unlimited |

## 3.3 Global ROI queue (cross-year) — **do this first**

| Priority | Goal ID | Goal | Why ROI | Years | Acceptance |
|---------:|---------|------|---------|-------|------------|
