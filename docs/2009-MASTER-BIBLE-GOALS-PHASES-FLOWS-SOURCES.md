# Part 1 — Overall goals

## 1.1 One-line goal

Build a **museum-grade 2009 Web immersion**: Windows XP + **Internet Explorer 8** shell (**Windows 7** optional late-year product, not forced January default), period sites, and **real local interactions** that recreate how people used the internet in calendar year **2009** — especially **iPhone 3GS + App Store scale**, **Facebook Like / FarmVille / Beacon end**, **Bing**, **Twitter real-time mainstream**, and **Android multi-handset** — while most people still live on the **desktop** Web 2.0 stack.

## 1.2 Visitor outcome (done = visitor can do this)

```
Hub → open 2009
  → XP desktop + IE 8 (Win7 optional late · Chrome product room, not sole shell)
  → Starting Point / About:
        238,027,855 sites · ~1.77B users
        thesis: social mainstream + apps daily · still mostly PC
        hard bans: iPad · Instagram · Spotify US · Uber mass · Win7-from-January
  → App Store: ~50k mid-year honesty · 1B+ downloads · install / remove · itt09-apps
  → iPhone 3GS: Jun 19 ship · $199/$299 · OS 3.0 · copy/paste · video · compass
  → Facebook: Like · Platform · FarmVille trail · Beacon shutdown Sep · FriendFeed buy
  → FarmVille: plant / harvest / neighbors · Flash canvas theater · itt09-farm
  → Bing: Jun 3 decision engine · search theater · itt09-bing
  → Twitter: Oprah / Kutcher culture · 140 · real-time · Iran coverage honesty
  → Windows 7 / IE 8 product rooms · Android multiphone densify · Chrome Mac/Linux beta Dec
  → Continuity: open Gmail · YT · Hulu · Netflix discs+stream · Spotify EU · Dropbox · Maps
  → Seeds (honest thin): Foursquare · Kickstarter · WhatsApp · Wave invite · UberCab about
  → Exit → hub resume · all state under itt09-* localStorage
```
