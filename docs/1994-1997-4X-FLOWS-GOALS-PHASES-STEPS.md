1. Incomplete REAL **never writes** `localStorage`.  
2. Prefix **`ittYY-*` only**. Isolation vs neighbor year.  
3. **Never invent brand pixels.** WA `id_` / WDM / Version Museum, or **failed-final**.  
4. Period facts only (1994–1997 in this file). No iPad, Gmail, Facebook, Wikipedia, Lucky-as-default.  
5. Do **not** add a 7th guided home step.  
6. Do **not** grow a dest-field forest. Prefer a second path on a live room.

8. Implement **one year** at a time.
