# 1994–1999 — what to improve (research, not implement)

**Date:** 2026-08-27  
**Status:** **Shipped 2026-08-27** — quiet homes, felt trails, leftover period labels, more.html theater, SSL / portal-wars costume, Napster emoji kill, text-first chrome. Stars locked. Guided 6. No new dest folders.  
**Scope:** Years **before 2000** that are live on disk — **1994, 1995, 1996, 1997, 1998, 1999**.  
**Ship law this file obeys:** live tree + hub + `scripts/itt_gate.py` `SHIP_YEARS`. Older markdown that disagrees is a notebook.

This file answers: *how can we improve these years more — UI, UX, flows, links, or otherwise?* It was written after reading the live trees, gold dests, leftover dests, year configs, official 10, leftover matrices, home rails, and the existing research/plan cluster.

It is **not** a dest-add bible. These years are already dense museums. Adding more folders would make the visitor problem worse.

---

## 0. One sentence

The early years already *have* the Web. A first-time visitor still has to fight the **museum dashboard** on top of it, then often lands on a leftover that says **Type leftover** instead of using the site.

If you only do three things:

1. **Quiet Starting Point** — star + guided 6 + the period page. Move the leftover warehouse to the flow map.
2. **Felt trail after the locked gold** — 1994 Yahoo after CSotD; 1997 eBay after PointCast. Do not move stars.
3. **Make leftover dests use the year** — Amazon Music / Mozilla / DMOZ / CDNow / Napster library / White House mail / IUMA helper, not “Open leftover.”

Do **not** start with: another 5× pack, a 6× leftover strip for 1994–1999, L1×5 file-count, new dest folders, a second gold, or a modern redesign.

## 4. The actual visitor problem

A 1994–1999 Starting Point is not a homepage. It is a **rail warehouse**. Typical stack on every home:

```
#itt-year-start          ★ one-thing + guided 6   (keep)
.itt-mass-honesty        felt-first / AOL #1      (keep, shorten)
[period banner / hero]   Yahoo ad, GeoCities, Napster banner

.itt-year-true-pack      residual leftovers

Destinations ul          period link list          (keep)
.itt-densify-trails      same trails again
.itt-densify-dir         room dump
.itt-5x-trails           F1–F5 → ★
.itt-5x-atlas            Help/Faq/Press/Legal × every site  (worst)
.itt-pop3x               first leftover trio
.itt-pop-more            second leftover trio

.itt-3x-links            more rooms
```

`css/year-start-quiet.css` already restyles the **star + guided** so they look less like a dark 2020 card. It does **not** hide the warehouse below. `e2e/year-3x3.spec.js` and `e2e/year-more-3x.spec.js` require `data-itt-pop3x` / `data-itt-pop-more` / `data-itt-pop-3x3` **somewhere on home** — they can be a one-line footer, not a third dashboard.

Then almost every dest (including gold) ends with:

- `itt-3x-also` dashed max-width strip
- `itt-4x-panel` “Yahoo leftover 2× / Type leftover / Hop leftover”
- sometimes `ITT-LO-OFFICIAL` two-tick leftover **and** a 5× leftover loop

So the visitor’s loop is:

```
Hub → year → fight the dashboard → click Yahoo
  → actually browse 1994
  → scroll into “Hop leftover” and think that is the site
```

That is the UX bug.
