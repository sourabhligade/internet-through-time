# UI robust pass — 2001–2008

**Date:** 2026-08-03  
**Goal:** Denser, more consistent XP-era Starting Points, flow maps, and signature product chrome without inventing brand pixels.

## What changed

### Shared kit
- **`css/period-xp-ui.css`** — Luna-blue page, silver Starting Point window (`.itt-start`), product chips, trail cards, bans box, XP buttons, map window, form controls
- Imported from **`period-2001.css`** and **`period-2002.css`** so years **2001–2008** inherit via the CSS chain

### Starting Points (`years/YYYY/pages/home.html`)
| Year | Work |
|------|------|
| **2001–2003** | Full rewrite to XP window + 5 product chips + trail cards + directory cols + bans |
| **2004–2008** | Retrofitted to `.itt-start` / `.itt-product-chips` / chip accent classes |

### Flow maps
- **2001–2008** `pages/map.html` use **`.itt-map-window`** (title bar + Starting Point / About links)

### Product densify CSS
| Year | Focus |
|------|--------|
| 2001 | Wiki shell frame · broadband speed panel |
| 2002 | Friendster header/buttons · KaZaA shell |
| 2003 | MySpace controls · iTunes store shadow |
| 2006 | Twitter card · Docs panel · compose button |
| 2007 | iPhone device frame · presets · Safari form |
| 2008 | App Store / Chrome install buttons · Hulu frame |

### Gates
- `e2e/2001-2008-ui-robust.spec.js` — 24 tests (home window · chips · map · shell iframe)
- `check-all-years` — 20/20

## Visitor-facing improvement

Before: 2001 full-width flat tables; 2002 loose top buttons; chips often plain text links; maps bare white page.

After: Every 2001–2008 year opens on a **centered XP Starting Point window** with **button chips**, **flow map CTA**, **trail cards**, and product pages with **clearer action buttons/status**.
