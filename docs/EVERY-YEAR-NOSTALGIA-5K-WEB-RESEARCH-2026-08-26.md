## 0. Honesty — what “5k websites for every year” is

It is a **research envelope**, not a dest target. Same lock as 4k / 10k.

```
ask: 5k websites / every year
  → research envelope (Gray + ILS June through 2018 + Netcraft January after + ITU people)
  → curate ONE nostalgia ritual per open year
  → NEVER 5,000 dests
  → NEVER a new leftover strip
```

A website on Internet Live Stats / Netcraft is a **unique hostname** that resolves to an IP. ILS’s own footnote: around **75%** of later hostnames are parked or similar. Hostname count is **not** “pages people used” and is **not** a museum file list.

| Envelope | Count | What it is | Museum job |
|----------|------:|------------|------------|
| Gray Wanderer Dec **1994** | **10,022** | Unique sites the 1994 web actually was | 1994 scale fact. The only year “~5–10k sites” is the whole Web. |
| ILS June **1994** | **2,738** | Mid-year cell. Yahoo launch row | Dual-cite with Gray Dec. Do not blend. |
| “5k websites” (this ask) | **~5,000** | A *walk budget*: notable + mass + year-true + Wayback + memory scholarship | Open primaries. Write one ritual. |
| ILS June **1996** | **257,601** | First year 5,000 is a rounding error | After this, 5k cannot mean dest count. |
| ILS June table last row | **2018 · 1,630,322,579 · −8%** | Last June hostname cell they publish | **No June 2019–2024 websites digit.** |
| Netcraft January (2019–2024) | ~1.08–1.30B hostnames | Different ruler. Active sites are ~190M | Print as **January**, never June. |
| ITU Facts and Figures | people-online % / billions | People, not hostnames | Never stamp as a websites cell. |

**This pass did not GET 5,000 live URLs per year.** It opened the scale blogs + nostalgia scholarship listed in §8 and lined every open year against **already-on-disk rooms**.

**What this research is *not***

- A list of 5,000 URLs to implement.  
- A claim that Alexa / SimilarWeb / Hosting.com ranks are gospel. Treat ranks as **direction**. If a rank fights a year `READ-FIRST` freeze, **the freeze wins**.  
- Adult top-10 entries as rooms. Name the rank if needed. Do not reconstruct.  
- Baidu / Yandex / Tmall / QQ as default US/English exhibit rooms unless a year already has that leftover.  
- Moving stars so Hampster Dance, FarmVille, or Wordle become the chip.  
- Restoring 2005 YouTube / 2006 Twitter / 2007 iPhone Safari.  
- Inventing a June ILS websites cell after 2018.  
- Autoplay MIDI on every lean door.

## 1. Why nostalgia is the right add (not more dests)

Period memory and later interviews keep repeating the **same five rituals**. They do not keep repeating “I wish there were more sites.”

| Ritual | What people say they miss | Museum shape |
|--------|---------------------------|--------------|
| **Wait** | Modem handshake. Fish Cam still. Skip Intro. Trial spinner. Zoom “joining.” GPT thinking. | Time + a Stop / Leave / Continue. Incomplete never writes. |
| **Sign** | Guestbook. Hit counter. “Cool site!” | Name + note. Empty never writes. |
| **Say hi** | ICQ UIN. AIM ding. You’ve Got Mail. Like. Mute. Send. Talk. | One named verb. Trap never writes. |
| **A homemade page** | Under construction. Webring. Netscape Now. Times New Roman welcome. | Personal / homestead rooms already on disk. Surface the GIF and the ring. |
| **A start page that was fat, then empty** | Yahoo packed → Google sparse → ChatGPT box. | Already the golds. The nostalgia is the *feeling of the empty/fat page*, not a 29th leftover. |

Olia Lialina / Dragan Espenschied (One Terabyte of Kilobyte Age; GeoCities research): the under-construction GIF meant **a person was still there**. That is museum-grade. A 5,000th leftover dest is not.

WIRED at 30 (2019), HuffPost millennial list (2025), How-To Geek GeoCities (2020), Lifehacker / Neocities (2023), NPR 90s brands (2016): same list — dial-up, GeoCities, guestbooks, AIM ding, Napster/LimeWire, Skip Intro, You’ve Got Mail. Later years rhyme: Like, square filter, cookie wall, Who’s watching, mute, empty prompt.

**Implication for this museum:** the rooms are mostly already curated. What’s missing is a **visitor-facing ritual layer** on the year card / About / optional sound. Costume still matters more than more URLs — especially **2014 / 2019 / 2020** gold dests (already diagnosed as 520px forms). This file does **not** rebuild those costumes. It writes the nostalgia copy and the sound/tour map so a later implement pass cannot invent dests.
