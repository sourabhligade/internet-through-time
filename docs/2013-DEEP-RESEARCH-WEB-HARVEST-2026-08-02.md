## 0. Thesis (locked draft)

**2013 is when the consumer internet’s “app layer” invents the formats that still define feeds today — short loops, ephemeral day-stories, flat UI — and when the public learns the stack is surveilled.**

Themes:

| Theme | Period truth | Why museum cares |
|-------|----------------|------------------|
| Short video | Vine 6s · IG Video 15s | Meme / creator seed before TikTok |
| Ephemeral | Snapchat Stories Oct | Stories paradigm (not IG Stories yet) |
| Design rupture | iOS 7 flat | End of skeuomorphic phone era |
| Hardware | 5s Touch ID · 5c color · A7 64-bit | Two-SKU iPhone year |
| Desktop | Win8.1 Start apology · Chrome #1 | Desktop still exists |
| Living room | PS4 / Xbox One | Console “next gen” |
| Politics of the pipe | Snowden / PRISM | Privacy as mass web literacy |
| Crypto noise | Bitcoin boom · Silk Road raid | Early mainstream crypto culture |
| Platform failure | Facebook Home | “Own the phone” hubris |
