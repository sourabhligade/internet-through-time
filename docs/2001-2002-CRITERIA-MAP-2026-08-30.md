## What “match other years” means here

A year is **not** dense enough if any of these is still true:

| Bar | Fail if |
|-----|---------|
| **V1 Variety** | Most site folders are **another year’s rooms** (2000 Amazon / Yahoo / Pets / Zombo / Baidu) with a year sticker |
| **V2 Amount** | Count of **year-true other websites** is a thin leftover list, not a peer mix of star + named leftover products + portals-as-costume |
| **V3 Number** | HTML went up by **reprinting 2000 pages**, not by adding 2001/2002 dests |
| **B1 Verb** | Visitor leftover is still **Type leftover** / **Save leftover** / **Do leftover** |
| **B2 Depth** | Official / named leftover dest is a **single** `index.html` with no second period page |
| **B3 Named leftover** | A leftover the from-scratch bible **named as a dest** is still not a folder, or is a 1-line stub |
| **B4 Listed** | Dest folder exists but Starting Point / map never links it |
| **B5 Games** | Famous cabinets ≠ 2, or year game is plaque-only |
| **B6 Honesty** | Room still *is* 2000 (IE 5.5 gold, MapQuest gold, Napster-as-monster, Pets as this year’s story) |

A year **is** dense enough when:

1. The **named 18** leftover dests exist as **that year’s** rooms.  
2. Each has a **year-true verb** + visible trap + second page (about / more / hop).  
3. Portals (Yahoo / Amazon / Google / CNN) are **costume leftover**, rewritten for the year — not a 2000 tree dump.  
4. Starting Point lists those dests. Famous = 2. Star + guided stay locked.  
5. HTML count is a **side effect**, not the goal.

**2004 is the variety peer.** 2004 is dense because it has **other 2004 websites** (Gmail · Flickr · thefacebook · Firefox · del.icio.us · Digg). It is not dense because Amazon has 23 pages.

Shared leftover machine:

```
open dest
  empty / trap / 0 ticks     →  no key
  complete year-true verb    →  ittYY-*  {real, multiStep, year}
  Next href HTTP 200
```
