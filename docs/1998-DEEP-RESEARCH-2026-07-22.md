## 0. One-paragraph thesis (verified)

**1998 is portal peak + the first cracks of the open web and modern search.** Yahoo / Excite / Netcenter / AOL / MSN fight for “stickiness” and TV ads (“Do you Yahoo!?”). Microsoft ships **Windows 98** (Jun 25) with IE glued in; DOJ **files** antitrust suit (May 18); trial opens Oct 19. Netscape open-sources Communicator (Jan 22) → **Mozilla.org** (Mar 31), then **announces sale** to **AOL** (Nov 24, ~$4.2B; closes 1999). **Google** goes Stanford → Inc. (Sep 4) → bare `google.com` beta (Dec); portals still own *usage*; **IE overtakes Netscape during 1998** (exact share % varies by survey). **Amazon** adds **Music** tabs (~Jun), acquires Junglee/PlanetAll (Jul), 3.1M customers — CDnow/N2K merge under pressure (Oct). **eBay**: Meg Whitman (Feb), My eBay (May), **IPO Sep** (priced $18 → open $53.50). **WaSP** launches (Aug); W3C **DOM Level 1** Recommendation (Oct 1). **BowieNet** ISP/community (Sep 1). Scale: **~2.41M websites** (Live Stats June 1998) vs 1.12M in 1997. Web design settles toward “form follows function” (Veen/Wired Jan–Feb) while Flash + frames + portal chrome still dominate mass sites.

## 3. Year grammar — how 1998 *feels* (for chrome + copy)

### 3.1 OS / browser (target)

| Layer | Spec | Evidence |
|-------|------|----------|
| OS | **Windows 98** (Jun 25 GA) | Microsoft PR; not pure Win95 |
| Default browser | **IE 4.01** family | Bundled with Win98; IE5 final is **Mar 1999** — label late-98 as “preview” only if shown |
| Secondary | **Netscape Communicator 4.x** still present, declining | Version Museum NN4; market flip end-98 |
| Address chrome | `Address:` (IE) not `Netsite:` | Continuity from 1997 IE room |
| Modem | **56k assumed** (not novelty) | Prior year 56k story; BowieNet review wants 56k |
| Push / Channels | Residual; less central than 1997 PointCast peak | Portals replace push as buzzword |

### 3.2 Design culture

- Veen: structure before presentation; toy-like limited-bandwidth aesthetic (Wired Feb 1998).
- Mass sites: **tables + GIF + frames** still king; CSS real but incomplete; Flash demos / designer sites (Hillman Curtis).
- Portal grammar: dense service strips, **My-*** personalization, stock tickers, chat, free email, partner shopping modules.
- Google anti-grammar: almost empty white page, blue links later — **academic sparseness** vs portal noise.

### 3.3 Scale & market mood

| Metric | 1997 | 1998 |
|--------|------|------|
| Websites (Live Stats June) | 1,117,255 | **2,410,067** |
| Users (Live Stats) | ~121M | **~188M** |
| Browser war | IE catching up | **IE overtakes NN** by end-year |
| Commerce | Amazon IPO year; eBay rename | Amazon multi-category; eBay IPO; CDnow peak→collapse trajectory |
| Search usage | AltaVista + Yahoo directory | Same **usage** winners; Google technology story only |
