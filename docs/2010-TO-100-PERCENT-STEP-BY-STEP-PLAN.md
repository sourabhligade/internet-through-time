### How achieved (steps — repeat for each ID)

1. Open CDX for year-correct URL:  
   `https://web.archive.org/web/*/http://…` · filter **2010**.  
2. Pick best timestamp · open **`id_`** capture.  
3. Extract logo/hero image URL.  
4. Download:  
   ```bash
   curl -fsSL --max-time 40 -o /tmp/h10.bin \
     "https://web.archive.org/web/{TIMESTAMP}id_/{ORIGINAL_URL}"
   ```  
5. Validate:  
   ```bash
   file /tmp/h10.bin
   # must be GIF / JPEG / PNG
   # REJECT: HTML, JSON, size < ~400 bytes, "1 x 1" tracker
   ```  
6. Install with `-wa` suffix:  
   ```bash
   mv /tmp/h10.bin assets/period/2010/<brand>/<name>-wa.<ext>
   ```  
7. Log in `docs/references/2010/CAPTURE-LOG.md`:  
   `| H10-0N | target | **[wa]** | path |`  
8. If fail: try **one** alternate CDX path same session.  
9. If fail again: log **`[failed-final]`** + reason. **Do not invent a logo.**  
10. Optional note:  
    `docs/references/2010/wayback-extracts/H10-0N-notes.txt`
