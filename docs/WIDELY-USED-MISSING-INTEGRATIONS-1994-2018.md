# Bottom line

The museum already has social, search, video, and many portals.  
The **biggest widely-used holes** are:

1. **AIM + MSN Messenger** (chat generation)  
2. **MapQuest** (pre-Google Maps life)  
3. **Pandora** (pre-Spotify US radio)  
4. **Photobucket + Imgur** (how images actually moved)  
5. **StumbleUpon** (discovery habit)  
6. **GitHub + Stack Overflow** (how code people used the Web)  
7. **Airbnb + Slack** (2010s trust markets + work chat)  
8. **Flash install / reCAPTCHA** (universal UX friction)
