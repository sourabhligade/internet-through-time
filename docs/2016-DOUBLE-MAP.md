## 4. How a visitor meets the double

Minute path. This is the live shell. The ten rooms join it as direct URLs. They are not on the directory, Starting Point, or the official trail.

1. Hub year number **2016** goes to `http://127.0.0.1:8080/years/2016/`.
2. `years/2016/index.html` is a stub. `ITT.YearUI.paint("2016")` builds the parent chrome, the directory bar, and `iframe#content`.
3. The iframe loads `pages/home.html`. That is Starting Point.
4. The star chip is Instagram Stories. One click from that chip opens `sites/instagram/stories.html` and is the only control that may write `itt16-ig-stories`.
5. The official trail under the page is the ten stops. Next labels walk Stories → GO → Reactions → WhatsApp E2E → iPhone 7 → Vine goodbye → Spectacles → musical.ly → Win10 upgrade ends → Gym Rush → back toward Stories.
6. A directory click in the **parent** changes the iframe `src`. The address bar stays `/years/2016/`.
7. A real link inside the iframe is caught by `wireDocument` (capture phase) and navigated inside the frame. The parent does not become the dest URL.
8. Parent CSS does not paint the iframe. The room’s own `period-2016.css` does.
9. Leftover rails, leftover-2× link strips, and workshop boards fold on first paint. They show when the URL has `?deep=1` or the visitor opens the drawer. I7. A yellow machine on Starting Point fails that rule.
10. A double room, once built, is reached from that folded shelf or from its own URL `years/2016/sites/<slug>/index.html`. It is not step 7 of the guided list and not n=11 on the official trail.

## 5. How one room writes

Template is the live Figma leftover face: `years/2016/sites/figma/index.html`. A future double room copies that shape. The save owner is `leftover-official.js`, not a new writer.

### 5.1 What is on the page

- `html[data-itt-year="2016"]`. No `data-official-key`.
- A `[failed-final]` line and the cite link until a real capture exists.
- Crumb back to Starting Point.
- One `<h1>` that names the verb.
- One panel:

```html
<section data-lo-panel="1" data-itt-dest-true="1" data-itt-year="2016">
  <button type="button" data-lo-pick="keep">Sell</button>
  <button type="button" data-lo-pick="trap">Reels as gold</button>
  <input data-lo-field>
  <button type="button" data-lo-trap>Trap</button>
  <button type="button" data-lo-save data-lo-key="marketplace-lx" data-lo-need-pick="keep">Sell</button>
  <p data-lo-status></p>
</section>
```

Honesty boxes are `[data-lo-req]` checkboxes. Two of them, same as Figma: “the chip is not this dest” and “empty / trap never write.”

`data-lo-key` is the suffix only. `keyOf` turns `2016` + `marketplace-lx` into `itt16-marketplace-lx`.

### 5.2 Clicks that write nothing

`bootOne` binds the save button once (`data-lo-bound="1"`). On click it stops the event, then refuses in this order:

| Visitor did | Status line | `localStorage` |
|-------------|-------------|----------------|
| Save with an unticked `[data-lo-req]` | “Tick honesty first. Incomplete never writes.” | unchanged |
| Save without the keep pick pressed | “Pick first. Incomplete never writes.” | unchanged |
| Save with the field empty or one character | “Type something first. Empty never writes.” | unchanged |
| Trap button `[data-lo-trap]` | “Trap. That click never writes.” | unchanged |
| Keep pick whose label is the trap (Reels, TikTok, a second star) | The save’s `data-lo-need-pick` is `keep`, so a trap pick does not satisfy it | unchanged |
| Save whose computed key equals an official `whenKey` with `n` from 1 to 10 | “Leftover never stamps the official key.” | unchanged |

The official keys that must hit that last refusal if anyone wires them by mistake:

`itt16-ig-stories`, `itt16-pogo`, `itt16-fb-react`, `itt16-wa-e2e`, `itt16-iphone7`, `itt16-vine-end`, `itt16-spectacles`, `itt16-musically`, `itt16-win10-end`, `itt16-game-gymrush`.

The double keys are new suffixes. They are not in `flow-trails.js`, so the refusal loop does not see them. They still must not write the star. The payload carries `leftover: true` and never the star key.

### 5.3 The click that writes

All of these are true on the same panel:

1. Every `[data-lo-req]` checkbox is checked.
2. The button `data-lo-pick="keep"` is on (`aria-pressed="true"` or `data-lo-on="1"`).
3. `[data-lo-field]` has at least two characters after trim. The stored `q` is cut at 80 characters.
4. The visitor clicks `[data-lo-save]`.

Then `localStorage["itt16-marketplace-lx"]` becomes JSON:

```json
{
  "multiStep": true,
  "real": true,
  "leftover": true,
  "year": "2016",
  "kind": "hops",
  "pick": "keep",
  "picks": ["keep"],
  "q": "the typed line",
  "ts": 0
}
```

`kind` is `hops` when the panel has pick buttons. Status reads `Saved · itt16-marketplace-lx`. A later visit sees the same line because `saved.real` is already set.

`year-2016-extras.js` also listens, in capture, on `[data-lo-save]`. It does not write storage. If the same gates pass and the field has two characters, it paints `[data-era-result]` with the `<h1>` and the typed line. If `html` has `data-official-key`, that listener returns immediately. Double pages must not set that attribute.

### 5.4 What the star still does

Stories stays the only writer of `itt16-ig-stories`. A leftover payload does not call the star writer. Finishing Marketplace does not mark the year chip done. The atlas gold for 2016 stays Stories.

### 5.5 Fold

`foldLeftoverRails` hides leftover panels on first paint, then **keeps** a panel that has `data-itt-dest-true="1"` (`isDestTrueLeftoverFace`). So the face on its own page stays visible. The workshop strips (`data-itt-2x-links` and the other rail markers) fold unless `?deep=1`.

A double page may show its own save panel. It must not dump the other nine rooms onto Starting Point. It must not paint a leftover-2× link strip as if this pass were `2x`.

Official pages that carry `data-official-key` keep leftover-2× first paint at 0. Do not add these ten as `data-itt-2x-links` on Stories, GO, Reactions, or the other official eight.
