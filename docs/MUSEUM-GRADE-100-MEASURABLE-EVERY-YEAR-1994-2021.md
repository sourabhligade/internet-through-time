## 1. What “museum-grade 100%” means here (countable)

A year is **100%** when **all ten gates** pass. Each gate is 10 points. L4 pixels (perfect WA logos, OEM toolbar crops, modem WAV) are **never** in this 100. They stay optional forever.

| Gate | Pass rule (disk, not vibes) |
|-----:|-----------------------------|
| **G1 Door** | `index.html` · `pages/home.html` · `about.html` · `map.html` · `js/config/YYYY.js` · immersion stub · guided `<ol>` = **6** · star chip present |
| **G2 Gold** | Locked writer exists · `data-next-flow` · gold key string · Next dest 200 · incomplete never writes (already e2e-locked) |
| **G3 Official 10** | `flow-trails.js` dest + `nextHref` all exist |
| **G4 3× + 3×3** | Both trios’ dest files exist · not the chip |
| **G5 2× leftover** | Every `e2e/2x-links.matrix.json` path + `data-4x-go` + next dest exist |
| **G6 flowMaps** | `ITT.flowMaps[YYYY]` exists · every map `href` exists |
| **G7 Famous / game** | `sites/playable/game.html` · `famous.html` · two `[data-famous]` cabinets on years that ship Famous |
| **G8 Shell costume** | Window / task / `<title>` match the year **plan** (NN / IE for 1994–2013; **Chrome habit** for 2015–2021) |
| **G9 Plan dests** | Every `sites/*.html` the *current* READ-FIRST / from-scratch **map** names for **this** year exists, **or** is marked **NEVER** (lean). Cross-year leftovers (2016 naming `years/2015/vine`) do not fail this year. |
| **G10 Scale cite** | About prints ILS June **or** explicit “ends 2018 / no June cell” after 2018 |

**100% = 10/10 gates.**  
This is **stricter** than the earlier “disk dest 100%” column (that only scored G1–G7 + G3 dests). Costume + plan honesty are now in the score.

**Do not use** old `[x]` / `[ ]` counts as the grade. 2016/2017 execute bibles still have every phase `[ ]` while the door is live. 2001/2002/2004 phase docs still have forest checklists. Those notebooks are not gates.
