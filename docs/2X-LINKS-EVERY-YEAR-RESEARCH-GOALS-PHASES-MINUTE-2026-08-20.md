## 3. REAL contract (every new dest)

Copy the 1994–2000 kit. Do not invent a second engine.

```html
<div data-4x-panel data-4x-kind="query" data-4x-min="2">
  <label>Period verb</label>
  <input data-4x-field maxlength="80">
  <button type="button" data-4x-go="SUFFIX">Do (theater)</button>
  <p data-4x-status></p>
  <p class="itt-next" data-next-flow hidden>
    <b>Next:</b> <a href="RELATIVE">Verb · live dest</a>
  </p>
</div>
```

| Kind | Incomplete (never writes) | Writes |
|------|---------------------------|--------|
| `query` | field shorter than `data-4x-min` (default 2) | `{multiStep, real, year, ts, q}` |
| `checks` | not every `[data-4x-req]` ticked | `{…, checks}` |
| `hops` | fewer than `min` `[data-4x-hop]` clicks | `{…, hops[]}` |
| `wait` | skip timer | `{…, waited:true}` |
| `toggle` | not off **and** on | `{…, toggled:true}` |

Key: `ittYY-<suffix>` via `YearExtras.forYear`. Dest of Next is **this year’s** gold or the next leftover room — never only `pages/home.html`. Neighbor prefix never appears.

**Banned (CI already fails these):** dest-field plaques (“I read the YYYY note” + theater check + type a note + Save), `data-min-req < 2`, `href="#"` action words with no hook.

## 4. Shared phases (every year)

Do **S0 → S1 → S2 → S3**. Stop after S0 until the year is named.

### S0 — freeze (20 min)

1. `ls years/YYYY/sites` — confirm every slug in that year’s N-table exists.  
2. Count `data-4x-go` in the year tree. If **18**, this year is Band A (deepen only). If **0**, Band B/C (ship 18).  
3. Lock star (`data-ott-one-thing`). Do not move it.  
4. Guided `<ol>` length stays 6.  
5. Stop.

### S1 — writers (Band B/C) or deepen (Band A)

**Band B/C (2001–2011, 2015–2018):** for each N1–N18, add the panel on the **existing** file. No `mkdir`. Wire Next → next row’s file.

**Band A (1994–2000, 2012):** for each single-page leftover, add **one** second page (`results.html` / `item.html` / `about.html`) that is the dest of a REAL verb. Add 2 inbound links from sibling rooms. urlMap the new file. Failed-final pixels OK.

### S2 — map + trail

1. `pages/map.html` lists N1–N18 (or the new second pages).  
2. After all 18 `whenKey`s exist, you may append n=11–20 on the official strip (`js/config/flow-trails.js` regenerate via `scripts/build-flow-trails.py`). Until then the strip stays 10.

### S3 — e2e + gates

```bash
python3 -m http.server 8080 --bind 127.0.0.1
# empty field → no key
# complete → ittYY-suffix · no neighbor prefix · Next visible · dest 200
npx playwright test e2e/YYYY-4x-flows.spec.js --workers=1

python3 scripts/check-all-years.py
```

Copy `e2e/1994-1997-4x-flows.spec.js`. Add `test:e2e:YYYY` only if missing. Existing `YYYY-mvp` / densify / trail stay green.
