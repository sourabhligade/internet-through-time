## How to use this file

| You want to… | Do this |
|--------------|---------|
| See what the year already does | Open **Walk today** links for that year |
| Decide a hole | Open the dest, walk the **wrong path** and the **gold path**, then tick **A\*** |
| Decide a new leftover room | Open **Walk today** (the dest is missing), read **Walk after**, tick **B\*** only if you still want it |
| Avoid a double | Open **Already on disk** — if that dest already covers the story, strike the row |
| Say no | Paste the id under **STRIKE** in the mark-up box |

| Tag | Means |
|-----|--------|
| **HOLE** | Visitor machine is wrong, or a required museum piece is missing. |
| **OPTIONAL DEST** | Year-true leftover room. Year already works without it. |
| **NOT A HOLE** | Stale bible, already shipped, cap-blocked, or count-padding. |

Shared dest machine (every new leftover dest):

```
open dest
  empty / trap / 0 ticks     →  no key
  complete year-true verb    →  ittYY-*  {real, multiStep, year}
  Next href HTTP 200
```
