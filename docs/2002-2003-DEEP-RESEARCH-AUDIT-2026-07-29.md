## 2. Thesis lock (re-confirmed from live Cybercultural 2026-07-29)

### 2002 — one line

**Always-on broadband becomes a felt minority habit; the blogosphere becomes an ecosystem; post-Napster P2P (KaZaA) is the music wild west; Wired proves big-site CSS; IE6 sleeps at ~90% while Mozilla 1.0 / Phoenix plant open hope; Friendster seeds the friend graph (mass often remembered as 2003).**

Pillars for the year shell:

1. **Always-on** — Pew Jun 2002: 21% of internet users / 24M adults · “information appliance”  
2. **Blogosphere** — Hiler ecosystem language · MT TrackBack · Blogger still Pyra · Daypop/Technorati class  
3. **P2P chaos** — KaZaA FastTrack · Morpheus kick → Gnutella · spyware / KaZaA Lite lore · **no iTunes Store**  
4. **Design split** — MTV broadband portal + Flash microsites **and** Wired all-CSS Oct 2002  
5. **Browser monopoly + phoenix** — IE6 peak · Mozilla suite · Phoenix 0.1 (not Firefox brand)  
6. **Social seed** — Friendster founding/early graph with honesty labels  

### 2003 — one line

**Social graphs, paid downloads, self-hosted blogs, and pro-blog ads go product-mainstream:** Friendster hits mass public scale; MySpace launches as HTML-customizable fun alternative; iTunes Music Store sells 99¢ AAC; WordPress 0.7 forks b2; LinkedIn opens careers; AdSense funds pro blogs after Google buys Blogger; Flash is peak creative default.

Pillars:

1. **Social software** — Friendster mass (~3M fall) · MySpace seed (~100k Oct) · HTML profiles · Facemash footnote only  
2. **iTunes Music Store** — Apr 28 · 99¢ · 200k+ → 400k+ catalog · 25M songs by mid-Dec · Mac first · Windows Oct · DRM AAC not free stream  
3. **Self-host blogs** — WordPress 0.7 May 27 · MT continuity · Blogger **by Google** (Feb acquisition)  
4. **Pro graph + ads** — LinkedIn May · AdSense content-targeted Mar → self-serve Jun  
5. **RSS reading** — Bloglines browser reader mid-2003  
6. **Peak Flash** — FWA / agency / BowieNet class culture  

### Continuity vs leap (2002 → 2003)

| Theme | 2002 | 2003 |
|-------|------|------|
| Social | Friendster **seed** | Friendster **mass** + **MySpace** launch |
| Music | KaZaA wild west · iPod gen2 · **no Store** | **iTunes Store 99¢** + KaZaA still wild |
| Blogs | Blogosphere word · TrackBack · Pyra Blogger | Google Blogger · **WordPress** · **AdSense** pro blogs · Bloglines |
| Design | Wired CSS + Flash | Peak Flash ubiquity + standards blogs |
| Browser | IE6 + Mozilla/Phoenix | Firebird path · still not Firefox 1.0 |
| Scale | ~38.8M sites | ~40.9M sites |
