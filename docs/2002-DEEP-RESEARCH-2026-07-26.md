## 0. Thesis (verified 2026-07-26)

**2002 is the year the always-on web and the social web start to feel inevitable.**

| Pillar | Visitor should feel |
|--------|---------------------|
| **Always-on** | Pew: broadband is a **minority** of users but changes behavior — “information appliance,” not “most adults” |
| **Blogosphere** | Named media ecosystem: TrackBack, Daypop, RSS 2.0, Technorati Cosmos seed, Plasticbag-era design |
| **P2P wild west** | KaZaA ~100M downloads; Morpheus/FastTrack chaos; no Music Store |
| **Standards** | Wired News **all-CSS** redesign (Oct) vs MTV tables + plugins |
| **Social seed** | Friendster founding/seed (mass public often **2003** — honesty labels) |
| **Browser** | IE6 ~90% sleep; Mozilla **1.0** suite (Jun 5); **Phoenix 0.1** (Sep 23) — not Firefox brand |
| **Continuity** | Amazon smile · sparse Google + **News-New!** · Wikipedia growth · Yahoo portal |

**Scale (Live Stats, June 2002):** **38,760,373** websites (+32% YoY) · **662,663,600** users.

**Handoff from shipped 2001:** Wikipedia + iPod/iTunes library + IE6/XP + warblogs/MT birth → densify into broadband + social graph + KaZaA + Wired CSS + Phoenix.  
**Full room matrix:** see [`2001-TO-2002-HANDOFF-DEEP-RESEARCH-2026-07-26.md`](2001-TO-2002-HANDOFF-DEEP-RESEARCH-2026-07-26.md) §3.
