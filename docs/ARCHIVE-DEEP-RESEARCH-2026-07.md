## 0. Executive findings

### The archive reality (critical for 1994–1995)

| Era | Wayback bulk coverage | Best sources for *look* |
|-----|----------------------|-------------------------|
| **1994–mid 1995** | Almost none (IA crawling starts ~1996) | Screenshots, museums, press photos, academic dumps |
| **Late 1995** | Sparse / accidental | WDM + Version Museum + contemporary press |
| **1996–1997** | **Gold** — real HTML/CSS captures | Wayback dated captures + live survivors |

**Implication:** 1994–1995 authenticity is a **screenshot reconstruction** problem. 1996–1997 can be **capture-driven rebuilds** from Wayback HTML + GIFs.

## 4. Asset harvest protocol (so research becomes pixels)

For each P0 site:

1. **Find** dated screenshot or Wayback capture (record URL + date).  
2. **Download** logo / chrome / icons (Wayback “save page” or crop).  
3. **Store** under `assets/period/<year>/<site>/`  
4. **Document** in `docs/references/<year>/ASSETS.md` — source, date, license note (educational reconstruction).  
5. **Rebuild** HTML tables/`font` to match structure — not CSS flex “retro.”  
6. **Diff** against anachronisms checklist (Amazon smile, multicolor eBay, Google UI, Win98 in 1997).  

### Anachronism blacklist (from archives + brand history)

| Don’t use before | Thing |
|------------------|--------|
| 2000 | Amazon smile arrow logo |
| ~1999 | Multicolor eBay wordmark |
| 1998+ | Peak glitter GeoCities as “1995” |
| 1998-06 | Windows 98 chrome in 1997 room |
| ever as full site in 1997 | Google search (domain reg only easter egg) |
