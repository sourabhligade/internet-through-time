## 1. Narrative — Cybercultural

| Field | Value |
|-------|--------|
| URL | https://cybercultural.com/p/internet-2004/ |
| Status | `[visited]` 2026-07-27 |
| Author | Richard MacManus · May 20, 2024 |

**Thesis lines to keep:**

- Web 2.0 era starts 2004 — Flickr · Gmail · Google IPO · first Web 2.0 Conference.  
- February: Facebook quietly at Harvard; Canada: Flickr; April: Gmail as native-feeling web app (JS technique later called Ajax).  
- “Social software” phrase — MySpace, Friendster, blogs, wikis, forums — **before** “social media.”  
- MySpace hits **1M users ~June 2004** and remains most popular social network for years.  
- Blogosphere + Technorati as proto-social; MT/Blogger culture.  
- Bloglines as browser-based RSS web app love letter (Jul 2004 RWW).  
- Firefox 1.0 Nov 2004 vs IE peak (~95% class counts).  
- Web standards momentum (WaSP / Microsoft.com CSS redesign Aug 2004 note).  
- Amazon as collection of web services / APIs.  
- Oct Web 2.0 Conference — business/investor audience; “Web as Platform.”  
- Year-end shoutouts: Google (IPO, vs Microsoft desktop) · Flickr (most buzz social software) · del.icio.us tags · Feedburner RSS stats.

**Do not invent:** exact user counts beyond sourced; modern Facebook UI; Yahoo-owns-Flickr in 2004.

### Gmail primary quotes (use carefully)

From Google press (Apr 1 2004):

- “free search-based webmail service”
- User never “file messages or try to find them” / delete under ~4 MB limits
- Search every email ever sent or received
- Preview testing; not full public floodgates

Museum may keep **1 gigabyte** visitor language (period secondary coverage) alongside “huge free storage vs multi-MB rivals.”

- **Tabbed browsing**
- Online fraud protection (phishing / spoofing identity)
- Integrated search services in toolbar
