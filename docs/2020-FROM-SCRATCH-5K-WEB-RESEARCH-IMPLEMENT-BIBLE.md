It is a **research envelope**, not a dest target.

The 2020 Web is **not** 5,000 sites. It is **about 1.2–1.3 billion hostnames** (Netcraft January class) of which **~189 million** answered as *active* in January 2020. Internet Live Stats’ last **June** cell is still **1,630,322,579 (2018)**. There is **no June 2020 websites digit** to invent.
