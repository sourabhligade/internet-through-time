Build a **museum-grade 2009 Web immersion**: Windows XP + **Internet Explorer 8** shell (**Windows 7** optional late-year product, not forced January default), period sites, and **real local interactions** that recreate how people used the internet in calendar year **2009** — especially **iPhone 3GS + App Store scale**, **Facebook Like / FarmVille / Beacon end**, **Bing**, **Twitter real-time mainstream**, and **Android multi-handset** — while most people still live on the **desktop** Web 2.0 stack.
