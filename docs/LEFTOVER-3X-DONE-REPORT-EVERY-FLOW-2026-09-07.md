```mermaid
flowchart TB
  OPEN[Open dest index.html] --> PANEL[Dest-true leftover panel]
  PANEL --> M1{Empty go?}
  M1 -->|yes| NW1[Never writes leftover or star]
  M1 -->|no| M2{Trap pick or miss hop?}
  M2 -->|yes| NW2[Never writes leftover or star]
  M2 -->|no| M3{Keep + 2 ticks + field ≥ 2?}
  M3 -->|no| NW3[Never writes]
  M3 -->|yes| W[Write leftover JSON]
  W --> STAR{Star key empty?}
  STAR -->|no| FAIL[FAIL]
  STAR -->|yes| NEXT[Same-year Next HTTP 200]
```
