## Banned in 1999 pack

- Amazon **smile** logo (2000+ Turner Duckworth)
- Modern Google logo / Material / app grid
- WinXP Luna / IE6
- Post-Napster P2P brands (Kazaa, LimeWire) as “1999 default”
- Streaming-app chrome (Spotify-era)

## Allowed that prior years banned

- **eBay multicolor** lettering (~1999–2012 system)
- IE5 default chrome (was “preview only” in 1998 room)
- Napster client window chrome (simulation GIFs/HTML only)
