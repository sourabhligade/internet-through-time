# 1995 Period Assets

## Provenance

Assets in `assets/period/1995/` are **museum reconstructions** drawn from documented
period screenshots and descriptions (Version Museum, Web Design Museum, Flickr yodelanecdotal,
Cybercultural, CHM). They are **not** official brand files.

| Path | Based on |
|------|----------|
| `amazon/logo.gif` | 1995 river-through-A + “Earth’s Biggest Bookstore” (Version Museum Amazon 1995) |
| `yahoo/logo.gif` | Red Yahoo! wordmark (1995 homepage frames) |
| `altavista/logo.gif` | Early Digital-era AltaVista wordmark style |
| `chrome/btn-*.gif` | Win95 3D toolbar button style matching NN2 screenshots |
| `geocities/icons/*` | Common early personal-web icon vocabulary |
