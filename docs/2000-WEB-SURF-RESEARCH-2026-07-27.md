## 0. One-line thesis

**2000 = bubble peaks then pops while web culture gets louder:** AOL–Time Warner “triumph” → NASDAQ peak **Mar 10** → crash hangover; **Amazon smile** + tab insanity; **Napster** mass culture war; **Flash 5** splash pages; blogrolls + social news; **IE 5.5 / Win98–ME** chrome — not XP, not Wikipedia, not streaming Napster, not Web 2.0.
