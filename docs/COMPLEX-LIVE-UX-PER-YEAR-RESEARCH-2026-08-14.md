## 0. How to use

| You say | You do |
|---------|--------|
| `implement live ux 1995 homestead` | That year only |
| `implement live ux 2006 Digg` | That year only |
| `implement live ux all years` | **Do not.** One year per pass |

### What “complex live UX” means here

Same bar as COMPLEX, aimed at **using** the product:

| Must | Must not |
|------|----------|
| ≥ **3 HTML pages** with different jobs | One page + three checkboxes |
| Visitor **does** something (queue, IM, pin, swipe, publish) | “I understand” literacy only |
| Incomplete **never** writes `ittYY-*` | One-click `setItem('1')` |
| Reload still shows the work | State dies on refresh |
| Home **COMPLEX chip** (not `data-ott-one-thing`) | Second star |
| Dedicated boot (module or year extras) | Inline script as the machine |
| e2e: empty blocked · complete persist · neighbor prefix untouched | Load-only smoke |

**Gold feel to copy (not files):** 1995 Amazon cart · 1997 ICQ · 2005 YouTube/Maps · 2018 GDPR Manage · 2020 Zoom join≠save.

### Hard rules

1. **Do not steal the one-thing.** Chip stays locked (table §1).  
2. Config + content only. **No engine fork.**  
3. Prefix **`ittYY-*` only**.  
4. **Never invent brand pixels.** CSS wordmark / failed-final.  
5. Lean years (2011–14, 2017–18, 2020): **+3 pages max**. Do not restore forests.  
6. Fat 2015 / 2016 / 2019: new machine in **year-true** rooms only. No Amazon CD clones.  
7. Gold product years (1995–97, 2005, 2017–18, 2020 Zoom): **do not rebuild the star.** This is a *second* machine.  
8. Do not scaffold **2021+**.  
9. Guided home `<ol>` stays **6 steps**. COMPLEX is a chip under P1 / “also”.

### Honest disk (2026-08-14)

The 2026-08-08 COMPLEX **primaries are mostly shipped** (AIM, MapQuest, Photobucket, Pandora, GitHub, Stumble, Imgur→Reddit, Airbnb, SoundCloud, Slack, Zoom, CSotD ritual, SO accept, campus graph). This file is the **next** complex layer — live UX that is still thin or missing as a *use* loop.

## 2. Shared implement (every year)

Copy COMPLEX **G0–G8**. Extra live-UX checks:

1. Read this year’s row + `YYYY-READ-FIRST.md` / about bans.  
2. `ls years/YYYY/sites/<product>` — **reuse** folders.  
3. Three pages: **index (do)** · **job (state)** · **about (honesty)**.  
4. Incomplete click → no write.  
5. Complete → `{ multiStep, real, year, ts, …typed }`.  
6. Home: one COMPLEX chip *below* the star, not a 7th guided step.  
7. `urlMap` + `titleMap` + flow-maps leaf.  
8. `e2e/YYYY-<product>-live.spec.js` — empty / complete / reload / isolation.  
9. `python3 scripts/check-all-years.py --years YYYY`.

**Typical files**


## 3. Per-year research (visitor path · already · bans · ROI)

Each year: **already on disk** · **why this product** · **3-page path** · **bans** · **ROI**.

### 1994 — IUMA listen · R3

**Already:** CSotD rotator, BBS last call, Yahoo 3-hub, FishCam, IUMA page + download bar in `media-1994.js`.  
**Why:** First time a band could skip radio. Live UX = **wait for the file**, then a helper plays.  
**Path:** `iuma/index` pick a residual track → `track` modem bar (existing) → `about` “no CD”. Write `itt94-iuma` only after bar completes + Play.  
**Bans:** No MP3 store, no invented IUMA logo.  
**Anti:** Don’t steal CSotD star.

### 1995 — GeoCities homestead · R3

**Already:** SSL gold · AuctionWeb · `geocities/homestead.html` + `my-homestead.html` exist, thin.  
**Why:** The 1995 *use* that isn’t shopping — you **published**.  
**Path:** neighborhood → title+blurb (min 2) → Finish writes → `my-homestead.html` **renders their copy** after reload. Webring still works.  
**Bans:** Not eBay. No 1-Click as a patent theater.  
**e2e:** extend `1995-homestead-webring.spec.js`.

### 1996 — My portal · R3

**Already:** Hotmail gold · portal wars 3-hit · `excite/my` / `yahoo/my` in later years; 1996 has `e2e/1996-excite-my.spec.js`.  
**Why:** Portals stopped being directories and became **your** start page.  
**Path:** open My → drag/toggle ≥2 modules → write `itt96-myportal` → reload layout sticks.  
**Bans:** Don’t rename AuctionWeb. No 2005 personalized Google.

### 1997 — Slashdot moderate · R3

**Already:** ICQ gold · PointCast · `slashdot/{index,story}`.  
**Why:** Score + moderate was the nerd public square.  
**Path:** story → post comment (min 8) → moderate one comment → reload same scores. Empty comment blocked.  
**Bans:** Many WA captures are 1998 — keep 1997 voice. No modern Reddit chrome.

### 1998 — Babel Fish · R3

**Already:** Lucky gold · textfiles.com · AltaVista rooms.  
**Why:** First mass “the machine speaks French.”  
**Path:** phrase (min 2) + pair (en→es) → result page persist → about AltaVista/SYSTRAN honesty. Empty phrase blocked.  
**Bans:** Not Google Translate 2006. No live API.

### 1999 — Napster search · R3

**Already:** AIM gold. Napster pages exist.  
**Why:** The product was **search**, not a file you can keep.  
**Path:** query → results residual **zero bytes honesty** → library list of *searches*. Write query only.  
**Bans:** No real MP3, no download payload.

### 2000 — eBay watch + bid · R3

**Already:** MapQuest gold · smile Amazon · ebay items.  
**Why:** Crash year still bid at midnight.  
**Path:** item → watch → bid ≥ min → `myebay` shows watch+bid after reload. Low bid blocked.  
**Bans:** No PayPal checkout as gold (PayPal is residual).

### 2001 — Wikipedia edit · R4

**Already:** MSN gold · UseMod pages. `itt01-wiki-pages` exists — **deepen to history**.  
**Why:** Edit is the live verb.  
**Path:** article → edit (min 8) → preview → history lists your row. Empty edit blocked.  
**Bans:** Not 2004 citation/wiki 1.0 chrome.

### 2002 — Netflix DVD queue · R3

**Already:** Stumble rotator · `netflix/{index,queue,genres}`.  
**Why:** The red envelope was a **queue you tended**.  
**Path:** add title → queue order → “mailed residual” flag. Empty add blocked.  
**Bans:** No streaming (that’s 2007+). No 2011 Qwikster as 2002.

### 2003 — iTunes 99¢ · R3

**Already:** Photobucket→MySpace · iTunes pages.  
**Why:** The 99-cent click trained a decade of stores.  
**Path:** browse → confirm 99¢ residual → library list persist. No real audio.  
**Bans:** No App Store (2008). No Apple Music (2015).

### 2004 — Flickr photostream · R3

**Already:** campus graph · folklore.org · flickr upload/tags.  
**Why:** Tags + stream, not MySpace glitter.  
**Path:** filename residual → tag → photostream page after reload.  
**Bans:** No Yahoo-owns-Flickr as the 2004 story (deal 2005).

### 2005 — Google Reader · R3

**Already:** Pandora/YouTube/Maps gold · `reader/`.  
**Why:** Power users lived in unread counts.

### 2006 — Digg bury/promote · R3

**Why:** The front page was a **fight**.

### 2007 — Street View · R3

### 2008 — App Store get · R3

## 5. Live UX notes (all years)

- **Feedback** uses existing `actionFeedback` / status lines — no toast library.  
- **Reload** must show the *thing* (queue, homestead, match list), not only “Saved.”  
- **Isolation:** write `ittYY-*` · `itt(YY±1)-*` untouched.  
- **Lean cap:** if a lean year already has 3 extra pages from a prior densify, **deepen in place** instead of adding a fourth product.  
- **Forest years:** COMPLEX chip + `data-itt-primary-year` on any clone you touch.
