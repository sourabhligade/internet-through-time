# 1995 Authenticity Research — Stop Guessing, Use Period Sources

**Problem with the current 1995 room:**  
Much of what we shipped is *invented* (PIL-generated logos, generic purple bars, approximate copy). That reads as “AI retro,” not nostalgia. Real 1995 nostalgia comes from **specific** fonts, icons, spacing, chrome bitmaps, and wording that people actually saw.

**Rule going forward:**  
No invented brand marks. Rebuild from **documented screenshots + archives + period asset dumps**. If we cannot source it, label it clearly as *placeholder* or omit it.

This dossier is the research base for a rewrite of `years/1995/`.

---

## 1. What “exact” means for a museum rebuild

| Layer | Must match period evidence | May approximate |
|-------|---------------------------|-----------------|
| Browser chrome layout (menus, buttons, Netsite field) | Screenshots of NN 2.0 on Win95 | Sub-pixel anti-aliasing |
| Site logos (Yahoo, Amazon river-A, AltaVista) | Trace from museum screenshots | Recolor for palette |
| Category names / IA (Yahoo hierarchy) | Contemporary lists | Depth of every leaf |
| Marketing copy (“Earth’s Biggest Bookstore”) | Documented slogans | Long body text |
| Personal GeoCities icons | Real UC GIFs from archives | Unique fan art |
| Exact HTML of dead pages | Rarely available for mid-1995 | Structure + look |

**Important archive caveat:** Wayback Machine’s bulk crawling starts mid-**1996**. True **mid/late 1995** often only survives as:
- Museum screenshots (Web Design Museum, Version Museum)
- Contemporary press photos / TV captures
- Personal Flickr uploads (e.g. Yahoo 1995)
- Research blogs that restored frames (e.g. Amazon Aug 1995 restoration by Taran Van Hemert)
- GeoCities torrent / One Terabyte of Kilobyte Age (mostly later years; use carefully for *icon style*, not always 1995-dated pages)

## 3. Site-by-site authentic specs (from sources)

### 3.1 Amazon.com (July–Aug 1995) — **do not use modern orange smile**

**Documented (Version Museum + restorations):**

| Element | Authentic 1995 | Our current mistake |
|---------|----------------|---------------------|
| Logo | Stylized **“A” with Amazon River path** through it; full **amazon.com** wordmark; tagline **“Earth’s Biggest Bookstore”** under/near logo | Orange smile (that’s **2000** Turner Duckworth) |
| Palette | **Lots of gray**, not vibrant; early web gray UI | Teal/purple “shop” skin |
| Offer | **Books only**; “more than one million titles” | Mix of later product culture |
| Features | Search; “Eyes and Editors” notification subscription; customer comments/reviews | We invent checkout aesthetics |
| Fulfillment story | Little inventory; order from distributors; days–weeks | Instant modern retail feel |
| Layout | Simple, document-like, gray; **not** tab farm (tabs = 1998+) | Sidebar shop layout from later years |

**Implementation rule:** Trace logo from Version Museum / Web Design Museum 1995 frame pixel-for-pixel (re-export as GIF). Background `#c0c0c0` / white document with gray chrome regions. Include Eyes/Editors as a real form feature.

**Sources:**  
https://www.versionmuseum.com/history-of/amazon-website  
https://www.webdesignmuseum.org/gallery/amazon-1995

### 3.3 Netscape Navigator 2.0 on Windows 95

**Documented features (software museums):**

- Frames, animated GIFs, JavaScript (LiveScript → JS Dec 1995 press with Sun)
- Mail & news integration stories
- Toolbar: Back, Forward, Home, Reload, Images, Open, Print, Find, Stop + **N throbber**
- Location field often labeled **Netsite:**
- Directory buttons: What’s New, What’s Cool, Handbook, Net Search, Net Directory, Newsgroups (varies by build)
- Win95 window: gradient blue title bar when active, gray 3D controls, system menu icon

**Asset pipeline (best authenticity):**

1. Download NN 2.0x from evolt / archive.org  
2. Run in Win95 VM (or 86Box)  
3. Screenshot empty window + Yahoo page  
4. Crop toolbar glyphs to `assets/gif/1995/chrome/`  
5. Match our CSS chrome to those bitmaps  

Invented CSS triangles for Back/Forward **destroy** nostalgia.

**Sources:**  
https://www.webdesignmuseum.org/software/netscape-navigator-2-0-in-1995  
https://www.versionmuseum.com/history-of/netscape-browser  
https://browsers.evolt.org/

### 3.6 GeoCities / Beverly Hills Internet (1995)

| Element | Authentic early |
|---------|-----------------|
| Brand | BHI → GeoCities during 1995 |
| Hook | Themed **neighborhoods** + free ~2MB |
| Early neighborhoods | Colosseum, Hollywood, RodeoDrive, SunsetStrip, WallStreet, WestHollywood; mid-year + CapitolHill, Paris, SiliconValley, Tokyo… |
| URL pattern | `geocities.com/Neighborhood/####/` |

## 8. Honest answer to “why didn’t you research hundreds of sources first?”

We did **some** research (`docs/1995-RESEARCH.md`) for *what to build*, then **implemented too fast with generated stand-ins**. That optimizes for “features work” and kills “I remember this exact logo.”

Nostalgia is **visual memory**. The correct pipeline is:

> **screenshot → asset trace → HTML structure match → only then interaction**

not:

> **feature list → invent graphics → hope it feels old**
