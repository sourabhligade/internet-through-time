## 2. Theses (exhibit labels)

### 2000
**The bubble peaks, pops, and culture keeps growing anyway.** AOL–Time Warner (Jan); NASDAQ peak Mar 10 then deflation; Amazon **smile** + tab insanity; Napster mass culture under RIAA fire; Pets.com meme; Flash 5; IE 5.5 / Win98–ME. Not Wikipedia, not XP, not Web 2.0.

### 2001
**The Web gains a memory and a portable jukebox under a solemn sky.** Wikipedia (Jan 15); Wayback public (Oct); iTunes library + iPod “1,000 songs” (not Store); IE 6 (Aug 27) + XP (Oct 25); Napster court endgame; warblogs + Movable Type (Oct). Not Friendster mass UI, not iTunes Store, not Firefox brand.

### 2002
**Always-on and social start to feel inevitable.** Pew: **21%** of U.S. internet users / **24M** adults home broadband (71% cable / 27% DSL); named **blogosphere** + TrackBack; KaZaA chaos; Friendster **founded 2002** (mass public often **2003** — label carefully); Wired all-CSS redesign (Oct); Mozilla 1.0 + Phoenix 0.1; IE6 monopoly peak. Not MySpace, not iTunes Store, not WordPress default, not Firefox final name.
