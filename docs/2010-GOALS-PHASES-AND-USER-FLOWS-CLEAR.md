# Part 1 — Overall goals

## 1.1 One-line goal

Build a **museum-grade 2010 Web immersion**: **Windows 7 + Internet Explorer 8** shell (XP residual honest; Chrome / IE9 beta as product rooms), period sites, and **real local interactions** that recreate how people used the internet in calendar year **2010** — especially **iPad**, **iPhone 4 + iOS 4**, **Instagram (iOS-only)**, **Facebook Open Graph / ~600M**, **Foursquare peak**, and **FarmVille peak** — while most people still live on the **desktop** and **Spotify is still Europe-only**.

```

  → iPad: $499+ · Multi-Touch · iBooks · App Store for tablet
  → iPhone 4: Retina · FaceTime · multitasking · Antennagate honesty · 225k apps
  → Instagram: filter · square · follow · iOS-only honesty · itt10-ig

  → Foursquare: check-in · mayor · badges · itt10-4sq
```
