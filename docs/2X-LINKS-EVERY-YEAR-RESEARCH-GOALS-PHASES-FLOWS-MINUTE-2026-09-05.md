## 4. Real vs mock (every new hop)

`scripts/audit-mock-flows.js` fails CI on:

| Class | What it is | Fail if we ship it as the 2× hop |
|-------|------------|----------------------------------|
| **DEST_FIELD** | Factory plaque: period note + theater check + dest-field + Save | “I read the 2013 leftover note” |
| **WEAK_REAL** | `data-min-req` < 2, or “I saw / I watched” as the save | One checkbox writes |
| **HASH_CTA** | `href="#"` with an action word and no `data-*` hook | “Search Yahoo” that goes nowhere |
| **UNWIRED** | Button / submit with no product, pack, or REAL hook | WARN — prove DEAD in e2e |

**REAL leftover hop (pass):**

1. Label is the **dest name** (Yahoo, YouTube, Facebook), not “leftover 2×”.  
2. `href` is `../<slug>/…` **this year** and HTTP 200.  
3. Landing dest has a leftover machine: period verb · trap never writes · empty / 0 ticks never write · complete writes `ittYY-<leftover>` **not** the star.  
4. Next after write lands on another live dest this year.  
5. Incomplete (Allow / Accept All / Join / trial / empty Lucky / App Store-as-2007-gold) never writes.

**On disk today, many leftover panels are still costume.** Example — `years/2013/sites/vine/record.html` leftover 2× block:

- CTA: “Hold leftover”
- Checks: “This is leftover, not the year star” / “Trap / empty / 0 ticks never write”
- Pick: “2013 leftover path” vs “Neighbor year (trap)”

That satisfies the leftover-official e2e contract and **fails Bar B**. Legal 2× does **not** clone this plaque onto more pages. Legal 2× either:

- adds a **mass hop** whose landing dest already has a period verb, or  
- **rewrites** that dest’s leftover CTA to the period verb (Hold 6s is already the gold; leftover on Vine is “watch a loop” / “revine”, not a second Hold).

Do **not** re-run `scripts/build-2x-links.py` / `double-2x-every-year.py` / `implement-2x-*.py`. Those injectors are how DEST_FIELD plaques got here.
