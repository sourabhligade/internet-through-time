### 0.5 Hard rules

1. Config + content + extras only. **No engine fork.**  
2. Storage **year prefix only** (`itt94`…`itt18`). Incomplete **never writes**.  
3. Never invent brand pixels. Failed-final / continuity / RECON only. Log every harvest in that year’s `CAPTURE-LOG.md`.  
4. **Do not rewrite** Amazon / Yahoo / Google / YouTube **forests**. Rebuild the **one dest room** named in the phase.  
5. One-thing per year **does not change**.  
6. **Do not add leftover rooms.** 3× + 3-more + extra-a/b are enough doors.  
7. **Do not dump raw Wayback HTML** into `years/`. Wayback toolbars, rewritten URLs, and mixed CSS look *less* period than a reconstruction. Harvest → notes + assets → rebuild our HTML.  
8. **Do not vendor AGPL.** oldweb.today · replayweb.page · pywb stay **outbound links**. No `ui.js` / `sw.js` in `/js`.  
9. **Do not vendor Ruffle + SWF.** Flashpoint / IA Flash = research. Year games stay museum JS.  
10. Lean years stay lean (≤ ~40–60 HTML). Forest years do not grow another Yahoo copy.  
11. When you change a dest that e2e already clicks, **update that year’s e2e in the same phase**.  
12. **Git only if asked.**
