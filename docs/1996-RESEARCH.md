# 1996 Research Dossier — The Internet Through Time

**Status:** Research complete · ready for implementation  
**Target immersion:** Late 1996 (Netscape 3.0 · IE 3.0 · portal wars · personal web peak)  
**Prior year:** 1995 (Windows 95 · Netscape 2.0 · Amazon · AuctionWeb · GeoCities birth)

This document is the museum brief for building `years/1996/`.  
Sources: Cybercultural year reviews, Web Design Museum, W3C, Internet Live Stats /
Matthew Gray lineage, Version Museum, Wayback (usable from late 1996), contemporary press,
Space Jam archive (live original).

## 1. Why 1996 is the next year

1996 is the year the Web becomes **society infrastructure** — not just a novelty.

| Metric | ~End 1995 | ~Mid / end 1996 |
|--------|-----------|-----------------|
| Websites | ~100,000 | **~257,601 (Jun 1996)** — still under 1M |
| Feeling | “Business discovered the Web” | “Portals *are* the Web”; stickiness; get big fast |
| Design tools | Tables, early frames, brand-new JS | **CSS1** (Dec) + **FutureSplash → Flash** (Aug–Dec) |
| Apps | Document pages + cart theater | **Webmail** (Hotmail), streaming, plug-ins as normal |
| Browser war | NN2 dominant; IE1 weak | **NN3 vs IE3** — first real parity challenge |

**Cultural signals:** NetDay96 (Clinton/Gore wire schools), Internet 1996 World Exposition
(“World’s Fair on the Internet”), Yahoo/Lycos/Excite IPOs (Apr), Space Jam movie site (Nov),
Internet Archive founded (May), Communications Decency Act / early content fights (background).

**Exhibit thesis:**  
1994 = “I can visit documents on the Internet.”  
1995 = “I can buy, bid, and get a free homepage.”  
1996 = “The Web is my starting point — portals, webmail, movie sites, and a design arms race.”

## 3. What changed from 1995 (design rules)

### Browser / OS chrome
| 1995 exhibit | 1996 exhibit |
|--------------|--------------|
| Win95 + **Netscape 2.0** | Win95 still (Win98 is 1998) + **Netscape 3.0** primary |
| IE 1.0 optional / weak | **IE 3.0** as real rival (optional skin or “also installed”) |
| Frames rare | **Frames common** on major sites (nav chrome, portal shells) |
| JS brand new / minimal | **JS normal** for status bar, image rollovers, simple validation |
| Plug-ins exotic | **Plug-in culture**: RealAudio, FutureSplash/Flash, Java applets |

### HTML / page design
| 1995 | 1996 |
|------|------|
| Tables for layout emerging | **Tables everywhere** (complex nested layout tables) |
| White pages + some gray | Brighter corporate color; still lots of gray GeoCities |
| Animated GIFs appear | **Animated GIF peak** — NEW!, fire, mail, under construction, spinning logos |
| Guestbooks / hit counters | Same + **webrings**, awards badges, “Best viewed in 800×600” |
| No CSS in practice | **CSS1 exists Dec only** — do **not** make 1996 look modern CSS |
| No Flash | **FutureSplash intro** optional (theater: “plug-in required” skip link) |

### Business / culture of the Web
- **Portals** = the product (email + search + news + directory + “stickiness”)
- **Banner ads** denser; “content is what differentiates portals”
- **Affiliate** beginnings (Amazon Associates story)
- Free **webmail** changes “email = ISP only”
- Movie / brand **event sites** (Space Jam) become cultural objects
- Dot-com **IPO / get big fast** energy in About copy

## 5. Browser chrome plan

### Primary: Netscape Navigator 3.0 on Windows 95
Visual / product differences from 1995 NN2:
- Still Win95 taskbar desktop (teal or period wallpaper optional; keep black desktop if project preference)
- Richer **Directory** / **Net Search** / **Net Directory** buttons
- **Plug-in** status messaging (“RealAudio plug-in loaded”)
- Standard vs **Gold** edition note (mail + Composer — can be About copy, not full Gold UI)
- Throbber still N; slightly more “multimedia browser” marketing copy
- Better frames support → content sites may use framesets

### Secondary: Internet Explorer 3.0 (optional toggle)
- First IE that “catches up” in press narrative
- Different toolbar icons, blue “e” branding
- Useful for browser-wars educational dialog
- Do **not** make IE majority default — NN still leader in late 1996

### Modem / connect
- Default **28.8**; optional **33.6** late year; 56k is mostly 1997
- Progressive image load still matters for GIF-heavy pages
- RealAudio “buffering” theater is on-brand

## 7. Site-by-site implementation notes

### Yahoo! (late 1996 portal)
- Denser than 1995: more categories, Random, new, ads, stock/sports teases  
- Table layout multi-column; yellow/purple brand cues from period screenshots  
- Search form prominent (directory + search coexistence)  
- Optional “My Yahoo” marketing strip (full personalization is later)  
- IPO / “portal” language in About

### Hotmail (HoTMaiL)
- Free web-based email is the *story*  
- Login → Inbox table (From, Subject, Date)  
- Compose + Sent theater via `localStorage`  
- Logo spelling **HoTMaiL**  
- Minimal chrome: form-heavy, utilitarian, blue links  
- Do not build modern Gmail

### Space Jam (1996)
- Dark space background, planet image-map navigation  
- Subpages: Jam Central, Junior Jam, Press Box, Lineup, Stellar Souvenirs, etc.  
- Heavy GIF animation culture without modern CSS  
- Easter eggs OK if period-accurate  
- Best reference: https://www.spacejam.com/1996/  
- Fair-use educational reconstruction; credit Warner Bros. properties as trademarks

### Amazon.com
- Still books-first  
- Push **1.1M titles** / search / “related titles” recommendation strip  
- Associates program footnote for authenticity  
- Cart + checkout theater from 1995, slightly richer  
- Watch river-A logo authenticity (no post-2000 smile mark)

### GeoCities
- Neighborhoods expanded; more homestead samples  
- Grammar: hit counter, guestbook, MIDI note, under construction, webring  
- **Still not** peak glitter-GeoCities 1998–99 — intermediate chaos  
- Path style `/Hollywood/1234/`

### AuctionWeb
- Keep name **AuctionWeb** (eBay rename = Sep 1997)  
- More categories/listings than 1995  
- Bid theater + feedback-ish notes if space  
- Utilitarian ugly-on-purpose HTML retained

### Excite / AltaVista
- Excite: portal packaging around search  
- AltaVista: clean full-text results; contrast human Yahoo directory

### Frames demo
- One serious frameset site (e.g. news or corporate)  
- Left nav + content pane — teach the pattern  
- Avoid frames on every page (museum fatigue)

## 10. Accuracy pitfalls to avoid

1. **Don’t rename AuctionWeb → eBay** (that’s September **1997**).  
2. **Don’t put Google** (research project 1996 at Stanford only; public product ~1998).  
3. **Don’t make CSS the visual system** — CSS1 is Dec 1996 and barely used.  
4. **Don’t ship real Flash/SWF** — theater + badge only.  
5. **Don’t peak-GeoCities 1998** (music autoplay hell, max glitter).  
6. **Don’t default to IE** — Netscape still primary late 1996.  
7. **Don’t use 56k as normal** — 28.8/33.6 era.  
8. **Don’t invent Amazon smile logo** — pre-smile river-A.  
9. **Space Jam trademarks** — educational reconstruction, credit properly.  
10. **Wayback early-1996 gaps** — prefer Web Design Museum + live Space Jam for visuals.  
11. **Hotmail spelling** — HoTMaiL, not modern Hotmail logo.  
12. **No social media** — ICQ is fringe late-year; no Friendster/MySpace.

## 11. Success criteria (museum bar)

A visitor should feel:

1. “Portals want me to *stay* — not just leave via search.”  
2. “I have free email in the browser (Hotmail).”  
3. “Movie sites are weird interactive playgrounds (Space Jam).”  
4. “Frames, GIFs, and plug-ins are normal.”  
5. “Microsoft’s browser finally feels like a real threat.”  
6. “Amazon feels bigger than the empty 1995 bookstore.”  
7. “GeoCities is where regular people live online.”  

Someone who lived 1996 should say:  
*“Yeah — Space Jam looked like that, and everyone was getting a Hotmail address.”*
