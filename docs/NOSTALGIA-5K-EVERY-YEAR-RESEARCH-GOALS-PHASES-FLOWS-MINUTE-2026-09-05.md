## 2. What “nostalgia we can add” is — and is not

Nostalgia is the *feeling of being in that year*: the site you actually opened, the verb you actually did, the costume of the browser.

| Kind | Legal? | How |
|------|--------|-----|
| Dest-name hop to a dest **on disk this year** | **Yes** | `../yahoo/index.html` · leftover machine on landing |
| Period leftover verb rewrite (Bar B) | **Yes** | “Sign guestbook” not “Go-LIVE leftover” |
| 3× also-this-year dest-name hops | **Yes** | Already-this-year dests only |
| Costume (gray Mosaic, Win95, IE6, iPhone Safari) | **Yes** | CSS / copy already in year shells |
| Playable leftover deepen | **Yes** | Inside existing `playable/*.html` |
| New dest folder | **No** | Dest farm. Cut-forest / lean doors stay. |
| Official 20 / guided 12 / second star | **No** | Frozen |
| Leftover 4× extra writer | **No** | Floor is already ≥2 |
| Boarded year tree (2014 / 2018–2025) | **No** | Hub locked |
| Back-dated memory (TikTok in 2013, Stories in 2015, ChatGPT in 1998) | **No** | Year-true or unlist |
| Baidu / VK / Yandex rooms to fill a US door | **No** | Ranker noise. Hop US dests on disk |

**Ceiling sentence:** leftover writers are already 2×. Official / guided / stars / dests / HTML cannot 2×. The only large legal nostalgia add is **year-true hops and leftover verbs on dests that already exist**.
