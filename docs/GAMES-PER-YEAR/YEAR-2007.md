## 2. How it works

### 2.1 Entities

| Entity | Symbol | Behavior |
|--------|--------|----------|
| Wall | `#` | solid |
| Floor | `.` | walk |
| Player | `@` | arrow move |
| Box | `B` | push if destination free |
| Pad A | `A` | teleport enter → Pad B exit |
| Pad B | `Bpad` | reverse |
| Goal | `G` | box **or** player on goal per level rule |
| Button | `o` | opens door if box on it |
| Door | `D` | solid until button |

**Level rule default:** get **box onto G**.

### 2.2 Teleport rules (minute)

1. When player or box **steps onto** pad A, instantly move to pad B’s cell **if free**; else no teleport (stay).  
2. Prevent infinite loop: after teleport, ignore pads until leaving a pad cell.  
3. Only one A and one B per level.

### 2.3 Controls

- Arrow keys / WASD  
- R restart level  
- N cheat next? **No** in prod; `?debug=1` only

## 4. Minute collision push

```js
function tryMove(dx, dy) {
  var nx = px+dx, ny = py+dy;
  if (isWall(nx,ny)) return;
  if (isBox(nx,ny)) {
    var bx = nx+dx, by = ny+dy;
    if (!isFreeForBox(bx,by)) return;
    moveBox(nx,ny,bx,by);
  }
  px=nx; py=ny;
  applyTeleportIfNeeded("player");
  checkWin();
}
```
