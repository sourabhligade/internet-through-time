## 2. How it works

### 2.1 Round

1. Deal 7 random letters from bag (Scrabble-ish frequencies simplified).  
2. Player types word using only available letters (or click tiles).  
3. Submit → if in dictionary and letters suffice → +score, remove used tiles, draw replacements.  
4. 90s timer; end → save best.

### 2.2 Scoring

| Len | Points |
|-----|--------|
| 2 | 1 |
| 3 | 3 |
| 4 | 5 |
| 5 | 8 |
| 6 | 12 |
| 7 | 20 |

Bingo (use all 7): +15.

### 2.3 Dictionary

- File: `js/games/data/words-en-2k.json` or embedded array in JS for no XHR issues under file/static.  
- Prefer **embedded** `var WORDS = { "cat":1, ...}` for simplicity (static museum).  
- Min length 2.  
- No offensive filter required if list curated.

  var r = rack.slice();
  for (var i=0;i<word.length;i++) {
    var j = r.indexOf(word[i]);
    if (j<0) return false;
