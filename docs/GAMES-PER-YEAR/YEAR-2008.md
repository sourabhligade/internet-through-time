## 2. How it works

### 2.1 Play

Start span. Left wall **anchor**, right **pipe**. Click near existing goo (≤78px) to stick a ball. Gravity + springs sag the structure. Path from anchor to pipe wins. Budget 26 goo; spent without a path writes a weaker score.

Canvas click while idle **starts** and does **not** also place.

### 2.2 Persistence

Win or spent budget with ≥1 goo:

```json
{ "gameId": "goospan", "year": "2008", "best": 92, "real": true, "multiStep": true, "reached": true, "goo": 6 }
```

`?fast=1` + **Start** writes 12. Load / far click writes nothing.

### 2.3 Test hooks

`data-goo-nodes` (includes anchors) · `data-goo-count` (goo only).
