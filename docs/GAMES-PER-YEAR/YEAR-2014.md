## 2. How it works

### 2.1 Board

| Param | Value |
|-------|-------|
| Grid | 4×4 |
| Canvas | 320×320 · pad 8 |
| Spawn | 90% **2** · 10% **4** on empty cell after each move |
| Slide | Compress + merge equal neighbors once per move |
| Score | +merged value |

Arrows / WASD / swipe.

### 2.2 Gold / death

- **Gold:** any tile ≥ **128** → win flash · `saveBest` · `{ gold:true }`  
- **Dead:** no empty + no legal merge · if score>0 `saveBest` `{ gold:false }`  
- **R** / New Game resets board · does not clear best
