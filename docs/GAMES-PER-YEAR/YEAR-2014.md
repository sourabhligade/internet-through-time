## 2. How it works

### 2.1 Rules (standard merge)

1. Board 4×4; empty cells 0; tiles powers of 2.  
2. Start: two random 2’s (10% chance 4).  
3. Swipe/arrow: slide all tiles to that direction; equal neighbors merge **once per move**.  
4. Merged tile value sum; +score equal to new tile value.  
5. After each successful move (board changed): spawn one 2 (90%) or 4 (10%) in random empty.  
6. Lose: no empties and no adjacent equals.  
7. Win: create 2048 (flag once; allow continue).

### 2.2 Move algorithm (minute — implement carefully)

For direction RIGHT (others by rotate):

```
for each row:
  compact non-zero to the right
  merge adjacent equals left-to-right within compacted
  compact again
```

**Critical:** each tile merges at most once per move.

Reference approach: treat row as array filter zeros → merge loop → pad zeros.
