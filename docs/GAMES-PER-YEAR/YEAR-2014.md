## 2. How it works

### 2.1 Board

| Param | Value |
|-------|-------|
| Grid | 4×4 |
| Start | Two leftover tiles (value 2) |
| Fold | Arrow keys or on-screen ←↑↓→ · matching neighbors merge (sum) |
| Score | Sum of merges |
| Write | **Two successful merges** **or** Tile A + Tile B leftover folds |
| New Fold | Resets board · does not clear best · does not write |
