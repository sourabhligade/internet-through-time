## 2. How it works

### 2.1 Room

- Grid **10×8** cells.  
- Floor pattern CSS (checker).  
- Wall strip top with wallpaper color picker (3 colors).

### 2.2 Furniture catalog (sidebar)

| id | name | size |  
|----|------|------|
| chair | Bean chair | 1×1 |
| table | Low table | 2×1 |
| plant | Spiky plant | 1×1 |
| lamp | Floor lamp | 1×1 |
| poster | Band poster | 1×1 (wall only row 0) |
| rug | Rug | 2×2 |

Click catalog → “ghost” attach to cursor → click empty cells to place if free.  
Right-click or Delete key removes selected.

### 2.3 Avatar

- One sprite cell.  
- Arrow keys move 1 tile if free / not blocked by furniture solid.  
- Click tile path walk optional (reuse clickscape BFS lite).

### 2.4 Sticky notes

- Button “Stick note” → prompt text max 40 chars → note object `{x,y,text}` on floor.  
- Max 12 notes.  
- Display as yellow CSS notes.

### 2.5 Social theater

- Status: `Visitors online: 3` (random 1–8 every 20s).  
- Fake chat line ticker: canned phrases every 15s (`Guest waves.` / `Someone dances.`).

### 2.6 Persistence

```json
{
  "gameId": "roomsticky",
  "year": "2002",
  "wall": "#6699cc",
  "avatar": {"x":1,"y":1},
  "items": [{"id":"chair","x":2,"y":3}],
  "notes": [{"x":4,"y":4,"text":"hi"}],
  "ts": 0,
  "real": true
}
```

Save on place/remove/note/move debounce 500ms.

### 2.7 Win condition?

None — **sandbox**. “Goals” for playable feel: checklist panel:

- [ ] Place 3 items  
- [ ] Leave a note  
- [ ] Sit on chair (avatar on chair tile)  

Completing checklist writes `roomComplete:true` + flash “Room is happening.”
