## 2. How it works

### 2.1 Physics

| Param | Value |
|-------|-------|
| Canvas | 320×480 (phone) or 400×480 |
| Gravity | 0.35 |
| Flap | vy = −5.2 |
| Scroll | pipes left 2.2 px/frame |
| Gap | 110–130 px |
| Bird hitbox | circle r=10 |

Tap / click / Space → flap anytime.

### 2.2 Pipes

- Spawn every 90 frames.  
- Random gapY.  
- Score +1 when bird.x passes pipe.x + width and not yet counted.

### 2.3 Collision

- Pipe AABB vs bird circle  
- Ground / ceiling die  

### 2.4 State

`READY (tap to start) → PLAY → DEAD (tap retry)`

First tap both starts and flaps.

### 2.5 Persistence

