## 2. How it works

1. World is a toroidal-ish wrap canvas arena.  
2. Pellets (small fixed mass) spawn randomly.  
3. Player starts small; move toward mouse or WASD.  
4. Overlap pellet → absorb · mass += pellet.  
5. Overlap AI cell: if player mass > AI×1.1 → eat; if AI > player×1.1 → die.  
6. Score = floor(player mass). On death, `YearGame.saveBest('blobrush', score)`.  
7. `?fast=1` · fewer AI · denser pellets · easier e2e.  
8. `window.__ittBlobRushEnd(score)` test hook ends run and saves.
