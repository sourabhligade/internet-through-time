## 2. How it works (document from code + intended UX)

### 2.1 Premise

Draw a polyline track with the mouse; place a sledder; **Play** simulates gravity/sliding; score by distance or flags reached.

### 2.2 Intended controls (verify against `sled.js` in Phase 0)

| Mode | Action |
|------|--------|
| Draw | mousedown drag adds points to line |
| Erase / Clear | button clears track |
| Play | physics run |
| Stop | halt |

### 2.3 Scoring

- Prefer **max X distance** or survival time.  
- On end / crash / stop: save if best.
