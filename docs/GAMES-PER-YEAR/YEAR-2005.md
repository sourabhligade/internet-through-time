## 2. How the game works (existing behavior — document as truth)

### 2.1 Premise

Hold mouse / Space to **climb**; release to fall. Fly a craft through horizontal gaps. Distance = score. Crash on wall/ceiling/floor.

### 2.2 Controls

| Input | Action |
|-------|--------|
| mousedown / touchstart / Space down | hold=true climb |
| mouseup / touchend / Space up | hold=false fall |
| Start button / click canvas when dead | reset |

### 2.3 Physics (from `heli.js`)

- Gravity-like: hold −0.42 / release +0.48 on vy  
- vy clamped ±7  
- dist += 1.4 / frame  
- gaps scroll left 2.8 px  
- hitbox ~ craft x=60  

### 2.4 Scoring

- Score = floor(dist) on death  
- `ITTGames.addScore("heli", sc, "Pilot")` already  

### 2.5 Year isolation addition

On die, **also**:

```js
saveYearBest("itt05-game-heli", sc);
```

JSON: `{ best, last, runs, ts, real:true, gameId:"heli", year:"2005" }`
