## 2. How it works

### 2.1 Grid

9 plots. Each plot state:

```js
{ crop: null|"wheat"|"corn"|"berry", plantedAt: 0, readyAt: 0, state: "empty"|"growing"|"ready"|"wilted" }
```

### 2.2 Crops

| Crop | Cost | Grow ms (prod) | Grow ms (`?fast=1`) | Sell |
|------|------|----------------|---------------------|------|
| Wheat | 5 | 15000 | 2000 | 9 |
| Corn | 12 | 30000 | 4000 | 22 |
| Berry | 20 | 45000 | 6000 | 40 |

### 2.3 Actions

1. **Select crop seed** in toolbar.  
2. Click empty plot → if coins ≥ cost, plant.  
3. Tick every 250ms: if now≥readyAt → state ready (gold outline).  
4. Click ready → +sell coins · empty.  
5. If now > readyAt + wiltGrace (60s prod / 8s fast) → wilted · click clear free.  
6. **Neighbor help** button: once per 2 min, instantly finishes **one** growing plot (fake neighbor name).

### 2.4 Starting resources

- Coins: **30**  
- Unlocked: wheat only; corn at total harvests≥3; berry ≥8

## 4. Minute offline catch-up

```js
function hydrate(plots, now) {
  for (var i=0;i<plots.length;i++) {
    var p = plots[i];
    if (p.state==="growing" && now >= p.readyAt) p.state = "ready";
    if (p.state==="ready" && now >= p.readyAt + WILT) p.state = "wilted";
  }
}
```
