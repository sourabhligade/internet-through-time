## 2. How it works

### 2.1 Flow (hotseat)

```
PICK_PROMPT → DRAW (45s) → PASS_SCREEN (“hand device”) → GUESS → RESULT → next
```

1. Player A sees prompt word (e.g. “rocket”) + distractors hidden.  
2. Draws on 400×300 canvas (black stroke, 4 colors).  
3. Clicks Done → canvas frozen · word hidden.  
4. Pass screen 2s.  
5. Player B picks among **4 words** (1 correct + 3 decoys from list).  
6. Correct: streak+1 · +10 score; wrong: streak 0.  
7. After 5 rounds → end.

### 2.2 Prompt bank

≥40 words easy nouns: cat, house, tree, car, sun, fish, phone, pizza…  
Decoys: random other nouns.

### 2.3 Drawing tools

- Pen sizes 2 / 5  
- Colors: black, red, blue, green  
- Clear button (only in DRAW)  
- Undo last stroke (optional Phase 4)

### 2.4 Persistence
