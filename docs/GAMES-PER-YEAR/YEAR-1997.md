## 2. How it works

### 2.1 Rules

- 7 columns × 6 rows grid.  
- Players drop discs into a column; gravity to lowest empty.  
- First to **4 in a row** (H/V/diag) wins.  
- Full board = draw.  
- Human = red (first); AI = yellow.

### 2.2 Lobby theater (before board)

1. Click **Find game**.  
2. Status lines (300ms each): `Searching lobby…` → `Found table #17` → `Opponent: Guest_###` → `Game start!`  
3. Enable board.

### 2.3 AI

- **Phase 1:** random legal column.  
- **Phase 2:** (1) win if can, (2) block opponent win, (3) prefer center columns, (4) random.

## 4. Minute algorithm — win check

```js
function hasWin(board, player) {
  // board[row][col] 0 empty 1 red 2 yellow; row 0 bottom or top — document choice
  var dirs = [[1,0],[0,1],[1,1],[1,-1]];
  for (var r=0;r<6;r++) for (var c=0;c<7;c++) {
    if (board[r][c] !== player) continue;
    for (var d=0;d<dirs.length;d++) {
      var dr=dirs[d][0], dc=dirs[d][1], n=1;
      for (var k=1;k<4;k++) {
        var rr=r+dr*k, cc=c+dc*k;
        if (rr<0||rr>=6||cc<0||cc>=7||board[rr][cc]!==player) break;
        n++;
      }
      if (n>=4) return true;
    }
  }
  return false;
}
```

Drop:

```js
function drop(col, player) {
  for (var r=5; r>=0; r--) { // row 5 = bottom
    if (board[r][col]===0) { board[r][col]=player; return r; }
  }
  return -1; // full
}
```
