## 2. How it works

### 2.1 Premise

A **hub map** shows 6–8 labeled “planets” (museum names: Arena, Stadium, Junior, Bugs’… use **generic**: Red World, Blue World, Jump Zone, Tune Tower, Court, Stars, Merch, Home).  
Game mode: a **target name** appears; click the correct planet before timeout. Streaks increase speed.

### 2.2 Modes

| Mode | Description |
|------|-------------|
| **Classic (default)** | 20 targets or 45s — click correct planet |
| **Tour** | Must visit each planet once in any order (collection) |

Ship **Classic** first.

### 2.3 Round flow

```
IDLE → Start → SHOW_TARGET (name + beep) → WAIT_CLICK
  → correct: +points, next target (faster)
  → wrong: −life or −combo
  → timeout: miss
→ RESULTS
```

### 2.4 Timing curve

| Targets cleared | Time allowed per target |
|-----------------|-------------------------|
| 0–4 | 2500ms |
| 5–9 | 1800ms |
| 10–14 | 1200ms |
| 15+ | 900ms |

### 2.5 Scoring

- Correct: +10 · combo+1  
- Combo ≥3: +5 bonus each  
- Wrong: combo 0 · life−1 (3 lives)  
- Timeout: combo 0  

### 2.6 Layout

- Full-width black/`#000033` background  
- Absolutely positioned planet buttons (circular CSS) with labels  
- Top HUD: Target · Score · Lives · Best  
- Bottom: Start · “Exhibit: Space Jam site →” link to `sites/spacejam/index.html`  

### 2.7 Persistence

## 4. Phases

### Phase 0 — Scaffold  
Static planet buttons + labels + Start. No scoring.  
**Acceptance:** Layout readable at 800×600.

### Phase 1 — Target loop  
Random target from planet ids; highlight correct on debug only; score on correct click.  
**Acceptance:** 5 correct clicks possible.

### Phase 2 — Timer + lives + curve  
**Acceptance:** Miss on timeout; game ends at 0 lives or 20 hits.

### Phase 3 — Storage + results  
**Acceptance:** Best persists.

### Phase 4 — Polish  
CSS planets, starfield (CSS gradients or tiny GIFs from `assets/gif` if any), reduced motion slows curve.  
**Acceptance:** Period feel checklist.

### Phase 5 — Links + e2e  
**Acceptance:** e2e start + one forced correct click via `data-planet-id` evaluate.
