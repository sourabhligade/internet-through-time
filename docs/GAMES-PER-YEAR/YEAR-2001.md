## 2. How it works

### 2.1 World

- Grid **12×8** tiles (canvas or CSS grid).  
- Tile types: grass · path · tree · rock · bank booth · water (blocked).  
- Fixed handcrafted map (not procedural).

### 2.2 Controls

- Click walkable tile → pathfind simple BFS 4-dir → walk step every 120ms.  
- Click tree adjacent → start **chop** action (progress 0–100% over 2s).  
- Click bank adjacent with logs → deposit.

### 2.3 Skills

| Skill | Action | XP | Level formula |
|-------|--------|-----|---------------|
| Woodcutting | Chop tree | +15 / log | level = floor(1 + sqrt(xp/50)) |
| (optional) Mining | Rock | +12 | same |

Inventory: max **8** slots; item `log`.  
Bank: infinite logs count.

### 2.4 Tree rules

- Tree has `chopsLeft` 3–5; each success gives 1 log if inventory space.  
- Depleted tree → stump for 8s → respawn.

### 2.5 UI HUD

```

[Save note: autosaves]

```

### 2.6 Persistence

```json

  "gameId": "clickscape",
```

Autosave every successful chop/bank + on `visibilitychange` hidden.

### 2.7 Anti-idle

No combat. Pure gather zen. Optional “Random event?” toast canceled (scope).
