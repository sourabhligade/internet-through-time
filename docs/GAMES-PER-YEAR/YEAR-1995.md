## 2. How the game works

### 2.1 Premise

A gray “Java applet” frame hosts **American checkers** (8×8, dark playable squares, men + kings). Default: **Human (dark) vs AI (light)**. Optional toggle: **2 players**.

### 2.2 Layout

```
+------------------------------------------+
| Applet Checkers — museum original 1995   |
| [======== Loading Java Applet… 72% ]     |  ← only first show / Start
+------------------------------------------+
| Status: Your move · Captures mandatory   |
|   a b c d e f g h                        |
| 8 . r . r . r . r                        |
| … board as buttons or canvas             |
| 1 r . r . r . r .                        |
+------------------------------------------+
| Mode: (•) vs Computer  ( ) Two players   |
| [Start new] [Resign]                     |
| Wins: n  Losses: n  Draws: n             |
+------------------------------------------+
```

Use **DOM grid of 64 buttons** (simpler a11y) or canvas. Prefer **DOM** for S–M.

### 2.3 Rules (implement exactly)

1. Board 8×8; play on dark squares only (row+col odd or even — pick one, stick).  
2. Dark moves first.  
3. Men move diagonally forward 1; capture diagonally forward (and **backward** optional — US common: men capture forward only; kings both). **Use:** men forward move + forward capture; kings both directions.  
4. **Mandatory capture** if any capture exists (simple: if captures available, non-capture moves illegal).  
5. Multi-jump: after capture, if another capture from landing square, continue same turn.  
6. King on last rank.  
7. Win: opponent has no pieces or no legal moves.  
8. Draw button after 40 moves without capture (optional Phase 4).

### 2.4 AI (minute — Phase 2)

**Level 0 (ship first):** random legal move.  
**Level 1:** prefer captures; else random.  
**Level 2 (optional):** 1-ply max captured pieces.

AI delay: **400–800ms** “Thinking…” status (period patience).

### 2.5 State machine

```
IDLE → LOADING → PLAYER_TURN ⇄ AI_TURN → GAME_OVER
         ↑______________ New game ______________|
```

### 2.6 Interaction detail

1. Player clicks own piece → highlights legal targets (yellow outline).  
2. Clicks target → move/capture; if multi-jump, keep piece selected.  
3. Illegal click → status “Illegal move.” no state change.  
4. After player completes turn → AI turn.  
5. GAME_OVER → update W/L/D counts in storage.

### 2.7 Persistence

```json
{
  "gameId": "checkers",
  "year": "1995",
  "wins": 2,
  "losses": 5,
  "draws": 0,
  "lastResult": "loss",
  "ts": 0,
  "real": true
}
```

Write only on GAME_OVER (or Resign). Not on mid-game navigation away (optional: save mid-board Phase 5).

### 2.8 Loading theater

- On Start: show progress bar 0→100% over **600ms** (or 200ms if reduced motion).  
- Text: `Loading Java Applet…` then `Applet started.`  
- Board disabled until complete.

## 5. Phases

### Phase 0 — Scaffold  
**Goal:** Page loads with empty 8×8 grid.  
**How:** Create game.html + 64 cells `data-r` `data-c`. Immersion + urlMap.  
**Acceptance:** Visible grid in shell.

### Phase 1 — Rules engine (no AI)  
**Goal:** Two-player hotseat full game.  
**How:** Implement listMoves, applyMove, kinging, mandatory capture, win detect. Unit-test via browser console helpers `window.__checkersTest`.  
**Acceptance:** Can play forced capture puzzle setup to win.

### Phase 2 — AI Level 1  
**Goal:** Default vs computer.  
**How:** After dark turn, `setTimeout` AI pick capture-preferring move.  
**Acceptance:** Full game vs AI completes without freeze.

### Phase 3 — Applet theater UI  
**Goal:** Loading bar + period gray applet chrome + status strings.  
**How:** CSS `border:2px inset` · `background:#c0c0c0` · Progress element.  
**Acceptance:** Visual matches Win95 applet vibe.

### Phase 4 — Stats storage  
**Goal:** W/L/D in `itt95-game-checkers`.  
**How:** On GAME_OVER / Resign. Display on IDLE.  
**Acceptance:** Reload page keeps counts.

### Phase 5 — Links + e2e  
**How:** home + playable links; e2e starts game, clicks a piece with legal move (seed board with one forced move via evaluate).  
**Acceptance:** e2e green.

### Phase 6 — Optional mid-game save  
**Goal:** Resume board.  
**Acceptance:** Optional forever.
