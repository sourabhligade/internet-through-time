## 2. How it works

### 2.1 Premise

You are a Portal voter. Five cards show:

- Fake author  
- Title  
- Blurb  
- “Genre”: movie / game / animation  
- Optional fake “file size”  

Rate each 0–5 blasts (buttons). Submit when all rated → “Today’s #1” = highest rated (tie → first). Save ballot.

### 2.2 Submission deck (fixed for determinism + e2e)

Ship 8 cards in code; each run picks 5 random **or** fixed daily seed from date. Prefer **fixed 5** for e2e simplicity Phase 1; random Phase 3.

Example cards:

1. “Stick Fight 0.1” — game — “Two sticks, one keyboard”  
2. “Skip This Intro” — movie — “30s logo animation”  
3. “Dial-Up Symphony” — animation — “Modem as music”  
4. “Basket Portal” — game — “Throw balls at logos”  
5. “My Band Site Splash” — movie — “Enter Site or die”  

### 2.3 REAL rules

- Submit disabled until every card has rating ≥0 explicitly chosen (use `null` until click).  
- Soft fail: status “Rate all five before submitting (not a soft mock).”  
- On success write:

```json
{
  "gameId": "portaljudge",
  "year": "2000",
  "ratings": {"1":5,"2":3,...},
  "winnerId": "1",
  "multiStep": true,
  "real": true,
  "ts": 0
}
```

### 2.4 UI

Flash-era dark page · orange/red vote buttons · “blam” language optional light parody without copying NG medals system exactly.

```
[Card]  Title / author / blurb
Rating: (0)(1)(2)(3)(4)(5)
...
[Submit ballot]
Result panel hidden until submit
```

### 2.5 Optional mini play (Phase 4)

Winner card type=game unlocks 15s **Banner Slap** mini (click 8 banners) — bonus points. Not required for G1–G3.
