## 2. How it works

### 2.1 Playfield

- 2×3 grid of “cubicles”.  
- Targets pop up 600–1200ms then hide.  
- Types:  
  - **Memo (70%)** — click +1  
  - **Coffee (20%)** — click +3  
  - **HR audit (10%)** — click −2 and flash red (avoid)

### 2.2 Rules

- One target visible at a time (Phase 1) or up to 2 concurrent (Phase 3).  
- Miss (expire) : combo break.  
- Round **45 seconds**.  
- Cursor is default; optional mallet CSS on hover.

### 2.3 Scoring

| Event | Score |
|-------|-------|
| Memo | +1 · combo++ |
| Coffee | +3 · combo++ |
| HR | −2 · combo=0 |
| Combo ≥5 | +1 extra on memo/coffee |

## 5. Minute spawn loop

```js
function schedule() {
  if (!running) return;
  var hole = randomEmptyHole();
  showTarget(hole, pickType());
  hideTimer = setTimeout(function() {
    if (stillUp(hole)) { miss(hole); }
    scheduleNext(700 + Math.random()*500);
  }, 600 + Math.random()*600);
}
```
