## 2. How it works

### 2.1 Play

Start → click two **adjacent** gems. Match 3+ clears, gravity fills, combo multiplies. Non-adjacent second click retargets. No match → swap bounces.

### 2.2 Scoring

`n * 10 * combo` per cascade wave. 24 moves. End with score > 0 writes `itt04-game-gemcascade`.

### 2.3 Fixtures (`?fixture=`)

| Name | Board | Use |
|------|-------|-----|
| `bounce` | Checkerboard | Swap 0↔1 cannot match |
| `match` | Row0 `0 0 1` + (1,2)=0 | Swap gem 2 ↔ 10 scores ≥30 |
| `zero` | Checkerboard | Start finishes with score 0, no write |
