## 2. How it works

### 2.1 Two layers

**A. Pet home (hub)**  
- Pixel pet sprite (DOM/CSS box art)  
- Meters: **Hunger · Happiness · Energy** (0–100)  
- Buttons: Feed (−shop points or free once/2min) · Play (opens minigame) · Rest (+energy, wait)  
- Display: Name (editable once) · Age days · Points  

**B. Minigame “Coin Catch”**  
- 30s · pet at bottom · coins fall · arrow keys / A-D move  
- +1 point per coin · end returns to hub with points added  

### 2.2 Pet simulation (minute)

Tick every **30s real time** while page open (and on load apply offline drain capped):

| Meter | Idle drain / 30s | Feed | Rest | After minigame |
|-------|------------------|------|------|----------------|
| Hunger | −2 | +25 | 0 | −5 |
| Happiness | −1 | +5 | +5 | +15 |
| Energy | −1 | 0 | +30 | −10 |

If hunger=0 for 3 checks: happiness −10 (pet “sad” art state).  
Pet never “dies” (museum-friendly) — only sad state.

### 2.3 Economy

- Starting points: **20**  
- Feed costs **5** points (if points <5, status “Need more points — play a game!”)  
- Minigame coins → points 1:1  

### 2.4 Persistence blob

```json
{
  "gameId": "petdash",
  "year": "1999",
  "name": "Pixel",
  "hunger": 80,
  "happy": 70,
  "energy": 90,
```

Key: `itt99-game-petdash`  
Write on: feed, rest, minigame end, rename.  
Load: apply drain based on `Date.now()-lastTick` capped at 2 hours equivalent.

### 2.6 Coin Catch rules

- Canvas 400×240  
- Player x position, y fixed  
- Coins spawn every 400–700ms at random x, fall 2.5 px/frame  
- Catch if AABB  
- Miss = no penalty  
- 30s timer
