## 2. How it works

### 2.1 Premise

You control a small **cursor/hand/stick figure** auto-running right. Press **Space / click** to jump over:

- **Splash walls** labeled `ENTER SITE` (must jump)  
- **Loading bars** (low obstacles — jump or trip)  
- **Skip pads** (optional touch for +score “you skipped!”)

### 2.2 Physics (minute)

| Param | Value |
|-------|-------|
| Canvas | 480×240 |
| Run speed | 3.2 px/frame → increases +0.15 every 400 distance |
| Gravity | 0.55 |
| Jump vy | −8.5 |
| Ground y | 200 |
| Player hitbox | 16×24 |

One jump only while grounded (`onGround` flag).

### 2.3 Obstacles spawn

- Every 90–140 frames spawn one obstacle type weighted: wall 50% · low bar 30% · skip pad 20%.  
- Gap between obstacles min 120px.

### 2.4 Collision

- Wall: AABB vs player → die  
- Low bar: same  
- Skip pad: if overlap and not already collected → +25 score · flash “Skipped!”

### 2.5 Scoring

- +1 per 10px distance  
- +25 skip pad  
- On die: if score > best save  

### 2.6 State machine

`IDLE → RUNNING → DEAD → IDLE`

### 2.7 Visual period feel

- Black canvas · neon green `#0f0` or white stick · comic “splash” rectangles with text  
- Scanline optional CSS  
- Pre-start: fake plugin banner “Macromedia Flash Player theater (museum JS)”
