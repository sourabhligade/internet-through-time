## 0. What “5× in real” means

A dest counts only if it is a **distinct HTML page** with a period action (writer or honest dead-end). These do **not** count as 5×:

| Fake 5× | Why it lies |
|---------|-------------|
| `?night=1` on the same `index.html` | Same room, new query string |
| `pages/error/404.html` as a chip | Error theater, not a year dest |
| 5× Yahoo / GeoCities clone leaves | Forest the museum already banned |
| Hash CTAs (`href="#"`) | Mock |

**Disk truth (this morning):**

| Band | On-disk HTML already on home+map | Unused real HTML | L1 still short after reuse |
|------|--------------------------------:|-----------------:|---------------------------:|
| Lean **2011–2020** | **all of it** (0 unused pages) | **0** | **83–188 new pages / year** |
| Forest **1994–2007** | most indexes | 9–86 leftover files | **0–132** after listing leftovers |

Games/toys/trails are 5×. **Links are not**, because lean years were built as 20–37 rooms, not 145–245 rooms.

## 8. How to check a new dest is real

```
home/map chip → existing HTML
        │
   empty / 0–1 checks → NO WRITE
        │
   period action complete → ittYY-<slug>-<page>  (only if writer)
        │
   Next → locked star of that year
```

- File exists under `years/YYYY/`
- Dual-cited if it is a **new dir**
- `data-itt-primary-year` on the page
- No `#` primary CTA
- Guided `<ol>` still 6
