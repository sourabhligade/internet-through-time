## 3. REAL contract (every new dest)

Copy the shipped kit. Do not invent a second engine.

```html
<section class="itt-4x-panel" data-4x-panel data-4x-kind="query" data-4x-min="2">
  <h2>Leftover literacy</h2>
  <p class="honest">YYYY leftover · incomplete never writes · not the chip</p>
  <p><label>Leftover<br><input type="text" data-4x-field maxlength="80" autocomplete="off"></label></p>
  <p><button type="button" data-4x-go="SUFFIX">Type leftover</button> <span data-4x-status></span></p>
  <p hidden data-next-flow data-next-when-key="ittYY-SUFFIX"><b>Next:</b> <a href="REL">live dest</a></p>
</section>
```

| Kind | Incomplete (never writes) | Writes |
|------|---------------------------|--------|
| `query` | field shorter than `data-4x-min` (default 2) | `{multiStep, real, year, ts, q, kind}` |
| `checks` | not every `[data-4x-req]` ticked | `{…, checks}` |
| `hops` | fewer than `min` `[data-4x-hop]` clicks | `{…, hops[]}` |
| `wait` | skip timer | `{…, waited:true}` |
| `toggle` | not off **and** on | `{…, toggled:true}` |

Key: `ittYY-<suffix>` via `YearExtras.forYear`. Suffix **must not** collide with the year gold (`csotd`, `ssl-checkout`, `chatgpt-plus`, `gpt4o`, `wa-install`, `vine-posts`, …). Use `-lx` leftover suffix.

Next dest is **this year’s** leftover room or the star — never only `pages/home.html`. Neighbor prefix never appears.

**Banned (CI already fails these):** dest-field plaques, `data-min-req < 2`, `href="#"` action words with no hook, invented brand pixels, 7th guided `<li>`, live models / ripped SWF / real payments.
