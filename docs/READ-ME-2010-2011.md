# What you have now — 2010 and 2011

Simple status. No research dump.

**Hub is 18 years: 1994–2011.**  
**2012 and later are not on disk.**  
Nothing was committed or pushed.

---

## How to open

1. Serve the site (if it isn’t already): `python3 -m http.server 8080 --bind 127.0.0.1`
2. Open the lobby.
3. Click **2010** or **2011**.

Skip the connect screen if it appears.

---

## 2010 — tablet + filter + Like on the web

**Feel:** Windows 7 + IE 8. Still a laptop year.

**The one thing:** Instagram (iPhone only). Pick a filter, write a caption, Share. No filter / empty caption = nothing saved.

**Also there**

- iPad (no camera, $499)
- iPhone 4 (FaceTime is Wi-Fi only + bumper letter)
- Facebook Like on CNN and IMDb (need both)
- FarmVille at its March peak (83.76 million), not “80 million on launch day”
- Foursquare, Twitter, YouTube, Imgur, Pinterest
- UberCab in San Francisco only (not UberX)
- Wave died 4 Aug · Digg v4 · Cablegate · EU browser ballot
- Game: Sling Nest (museum pebble, not Angry Birds art)

**Storage:** `itt10-*` in this browser only.

**Tests:** `npm run test:e2e:2010` — last run **54/54 passed**.

**Left:** real 2010 logos (we didn’t invent pixels). Continuity rooms (Google, Chrome, etc.) are thin chips.

## 2011 — Circles, Spotify US, Siri

**Feel:** Windows 7 + IE 9. January was still IE8; the year-shell is IE9.

**The one thing:** Google+. Circles, +1, Hangouts. Invite FOMO. It did **not** replace Facebook.

**Also there**

- Spotify in the **United States** (14 Jul). Invite + two honesty boxes. No real music stream. EU was 2008.
- iPad 2 (this one **has** cameras)
- iPhone 4S / Siri (ask weather or “remind me to call Mom”)
- Facebook Timeline (profile becomes a memoir)
- Airbnb: search city → pick listing → message the host
- Instagram still iOS only (Android is 2012)
- Twitter, Groupon IPO year, Tumblr
- Snapchat seed (snaps, **not** Stories)
- Netflix Qwikster (announced, then cancelled)
- Game: Letter Swap

**Storage:** `itt11-*` in this browser only.

**Tests:** `npm run test:e2e:2011`.

**Research (this pass):** [`2011-FROM-SCRATCH-RESEARCH-GOALS-PHASES-FLOWS-MINUTE-VISITED-2026-08-17.md`](2011-FROM-SCRATCH-RESEARCH-GOALS-PHASES-FLOWS-MINUTE-VISITED-2026-08-17.md) · **10,320** unique corpus URLs.

**Left:** real 2011 logos. 2011→2012 handoff is skipped because 2012 isn’t built.

**Do not restore** any old 100-room 2011 forest.
