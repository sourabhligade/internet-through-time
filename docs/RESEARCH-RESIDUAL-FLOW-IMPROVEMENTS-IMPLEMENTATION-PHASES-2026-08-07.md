# 1. Global rules (every phase)

## 1.1 Never violate

1. Educational · **localStorage only**.  
2. **Never invent brand logo pixels** — CSS RECON + wordmark text · CAPTURE `[wa]` or `[failed-final]`.  
3. Incomplete multi-step → **no** `localStorage` write.  
4. Year-true bans (no Meta early · no Reels · no COVID · no real torrent payloads · Marshmello is **2019** not 2018).  
5. Prefix isolation: `itt` + 2-digit year.  
6. Prefer **one primary year** fully densified before residual copy into adjacent years.  
7. **Do not delete** working product hooks (`data-nf-save`, `data-mly-save`, …) when adding `data-ott-*` — dual-hook pattern (see Netflix 2017 merge).

## 1.2 Shared touch list (per product densify)

```
years/YYYY/sites/<product>/          # multipage HTML
js/immersion/year-YYYY-extras.js     # bootXxx + bootAll register
js/config/YYYY.js                    # urlMap entries for every new .html
js/config/flow-maps.js               # trail nodes
years/YYYY/pages/home.html           # chips / dual trails
docs/references/YYYY/CAPTURE-LOG.md  # H-row
e2e/YYYY-densify.spec.js             # or product-real.spec.js
css/period-YYYY.css                  # optional RECON classes
css/one-thing-products.css           # shared ott chips if needed
```

## 1.3 Dual-hook pattern (minute)

When densifying a page that already has product REAL:

1. Keep existing `data-prod-*` hooks.  
2. Add `data-ott-click` on interactive steps.  
3. Add optional second panel `data-itt-real-save` with **different** `data-storage-key` if one-thing key differs from product key.  
4. Never replace product boot with only generic real-flow.  
5. e2e both: product suite + `one-thing-per-year` still green.

## 1.4 Trail pattern (minute)

A **dual trail** is not only two chips. Ship:

1. Home: two chips with shared label e.g. `Trail · Photobucket → MySpace`.  
2. Room A: “Continue trail → Room B” link with `data-ott-trail="photobucket-myspace"`.  
3. Room B: reverse link + literacy checkbox “hotlinks powered MySpace images residual”.  
4. `flow-maps.js` year map: node A → node B edge.  
5. Optional e2e in `YYYY-trail-real-flows.spec.js`: incomplete blocked · complete may write trail key `ittYY-trail-<slug>`.
