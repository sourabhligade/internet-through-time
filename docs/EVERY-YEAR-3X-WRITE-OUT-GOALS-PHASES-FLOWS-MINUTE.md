## 0. What “3×” is (every year)

Three leftover **websites**, then **three more**, then **three more**. Not 3× more golds. Not a 10,000-room forest. Gray’s **10,022** (Dec 1994) is the size of that year’s Web, not a dest backlog.

```
Hub → YYYY → Starting Point
        ★ gold (locked)              ittYY-<gold>
        guided 6 (locked)
        │
        ├─ first 3×    [data-itt-pop3x="YYYY"]     ittYY-pop-<id>
        ├─ second 3×   [data-itt-pop-more="YYYY"]  ittYY-pop-<id>  (or leftover extras on 2020)
        └─ third 3×    [data-itt-pop-3x3="YYYY"]   ittYY-pop3-<id>
```

**Done for a year when**

1. Home has three strips, **3 live hrefs each**.  
2. First / second / third are **pairwise unique**, and **none is the star** — except **2007 · 2009**, where second **is** a copy of third (lean, written down, not dest-filled).  
3. Empty / no pick / 0 ticks **never writes**. Complete writes `{ real, year:"YYYY" }` under `ittYY-*` only.  
4. Guided `<ol>` still has **6**. Star href unchanged.

**Not done if** the chip moves, guided becomes 7, we invent a June 2019/2020 websites digit, restore 2014, or dest-fill Discord / Netflix / adult / google.com to hide a duplicate.

### Machine (every leftover 3× room)

```
open leftover room
    │
    ├─ Go with 0 picks / 0 ticks / empty field
    │      → status scold
    │      → write nothing
    │
    ├─ pick a row          [data-pop-pick]   (if the room has picks)
    ├─ tick every          [data-pop-req]    (if the room has honesty)
    ├─ type ≥2 in          [data-pop-field]
    └─ Go                  [data-pop-go]
           → ittYY-pop-<slug>   or  ittYY-pop3-<slug>
           → Next [data-next-when-key] to the next leftover dest
```

Costume: `[failed-final]` / RECON. 1994–2008 first 3× may still be field+go (no picks). Second + third always pick+honesty where the dest grew a panel.
