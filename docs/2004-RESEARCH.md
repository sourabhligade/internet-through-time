## 0. One-line thesis

**2004 is the hinge into Web 2.0:** **Thefacebook** seeds a campus social graph; **Flickr** makes photo sharing + tags a product; **Gmail** proves a rich browser app (invite-only, ~1 GB pitch — often mistaken for an April Fools joke); **Google IPOs**; the first **Web 2.0 Conference** sells “the Web as platform” to business; **Firefox 1.0** (Nov 9) challenges IE’s peak dominance. Mood = social software + blogosphere + early Ajax web apps — **not** YouTube, **not** open-to-everyone Facebook, **not** Chrome browser, **not** smartphone defaults.
