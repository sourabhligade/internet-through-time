## 0. What this program is

The real Web grew from **10,022 websites** (Matthew Gray, December 1994) to **1.63 billion hostnames** (Internet Live Stats June 2018, last cell). This museum ships **26 playable years** (1994–2013 + 2015–2020). We curate **mass + signature + leftover trio**. We do **not** reconstruct the other 9,994 (1994) or the other 172 million (2008).

This bible turns that research into **goals, ordered phases, minute file-level steps, and an end-to-end check** for every live year.

```
Hub
  → one Start  or  one Resume
    → year shell (period OS + browser chrome + iframe)
      → Starting Point (star + guided 6 + year page)
        → ★ gold product verb  (incomplete writes nothing)
        → mass leftover if the chart demands one room
        → About (June ILS digit, labeled second number, bans)
    → Exit · only ittYY-* keys
```

## 2. Global goals (the program)

### 2.1 Visitor outcome (whole museum)

A first desktop visit, no `docs/` file open:

```
1. Land on /                 → one Start, one Resume (if last year exists)
2. Enter a year              → period desktop, not a lecture
3. Hit Starting Point        → ★ one-thing is the first link
4. Do the gold verb          → key writes · reload persists
5. See one mass leftover     → Yahoo 2000–05, YouTube 2009, etc.
6. Open About                → June digit + labeled second number + bans
7. Year menu / ×             → back to hub
8. Come back tomorrow        → Resume opens the last live year
```

### 2.2 Research-faithful exhibit (what “done” means per year)

For **every** live year the visitor can answer, from the year itself:

1. **How big was the Web?** June ILS (or “no June cell” after 2018).  
2. **What did people actually open?** Hosting.com June top 10 is reflected as *mass leftover or honesty*, not as 10 new rooms.  
3. **What is the year object?** The gold verb (already shipped).  
4. **What is banned?** Visible on About.  
5. **What did we refuse to build?** 10k / 17M / 172M hostnames, adult, Baidu-fill, 2014, 2021+.

### 2.3 Non-goals

- Scrape or reconstruct 10,000 / 100,000 / 1,000,000 sites.  
- Rebuild `google.com` as a dest in 2007–2020.  
- Restore 2014 or scaffold 2021+.  
- Change gold keys in `e2e/one-thing-per-year.spec.js` without a freeze.  
- Modernize 1996 into a 2020 marketing site.  
- Merge the games wing into year shells.

```

     npx playwright test e2e/one-thing-per-year.spec.js --grep YYYY --workers=1
C. Edit only the files listed in that phase.
D. Incomplete path → no write. Complete path → write. Reload persists.
E. Year prefix only (ittYY-*). No neighbor-year keys.
F. Guided <ol> still exactly 6.
```
