## 0. One-line thesis (confirmed by sources)

**2004 is the hinge into Web 2.0:** Thefacebook seeds a campus social graph; Flickr makes photo sharing + tags a product; Gmail proves a rich browser app (invite-only, ~1 GB — often mistaken for an April Fools joke); Google IPOs; the first Web 2.0 Conference sells “the Web as platform” to business; Firefox 1.0 challenges IE’s peak dominance. Mood = **social software** + blogosphere + early browser apps — **not** YouTube, **not** open Facebook, **not** Chrome, **not** smartphones.

## 3. Year narrative — Cybercultural “Internet 2004”

**URL:** https://cybercultural.com/p/internet-2004/  
**Author:** Richard MacManus · May 20, 2024  
**Status:** Full re-read 2026-07-30  

### 3.1 Opening thesis (paraphrase / key lines)

- The next era of web technology starts in 2004 — Flickr + Gmail, blogging + RSS as social software, Google IPO, first Web 2.0 Conference.  
- **2004 = year Web 2.0 truly began.**  
- February: Facebook quietly launched in a Harvard dorm room.  
- Same window (Canada): Flickr photo sharing.  
- April: Gmail — one of the first web apps that worked like a native app.  
- The JavaScript technique would later be termed **“Ajax”** (popularized **2005** — do not brand as 2004 product name).  

### 3.2 Read/write web & vocabulary

- Significant early-2004 energy before a settled name.  
- Blogging + wikis: ordinary people writing without deep technical skills.  
- Flickr + **del.icio.us** enabling sharing.  
- Period phrases: **“read/write web”** (Berners-Lee lineage) and **“two-way web”** (Dave Winer).  
- MacManus’s blog named **Read/Write Web**.  

### 3.3 Social software · blogosphere (not “social media”)

- **Before social media.** Phrase used by web geeks: **“social software.”**  
- Encompassed: MySpace, Friendster, Blogger, LiveJournal, Wikipedia, forums/message boards.  
- **June 2004:** MySpace reaches **~1 million users** — remains most popular social network for nearly four more years (cited Atlantic rise/fall piece).  
- Blogging still niche but increasingly where daily online conversation happens.  
- Author switched to **Movable Type** (browser-based) early May 2004 (from Radio Userland).  
- Blogosphere = decentralized prototype for social media — but not very diverse; Technorati top blogs often politics/tech.  
- Technorati (1 July 2004 frame) more focused on blog search.  

### 3.4 Browser power · web apps

- Rise of **browser-based web apps** is a key 2004 tech trend.  
- **Bloglines** love letter (July 2004 RWW): browser apps easier, no install, any computer online; trade-offs vs rich clients.  
- More than a year before Google Reader (2005).  
- **Firefox 1.0** launches November 2004 — needed because Microsoft at peak browser dominance.  
- Some counts: IE ~**95%** market (period TheCounter April 2004 class).  

### 3.5 Web standards momentum

- Web Standards Project (WaSP) momentum (Molly Holzschlag era).  
- Eric Meyer note (Aug 2004): Microsoft.com redesign uses CSS, drops tables/spacer GIFs; HTML weight dropped to ~27–30% of previous IE-specific versions.  

### 3.6 Websites → web services

- Digital Web Magazine piece (Apr 2004): sites as collections of loosely-coupled **services**, not “places.”  
- **Amazon** as example: knows name, recommendations, “what’s new since last visit,” partner programs, reviews, third-party APIs.  

### 3.7 Silicon Valley revival · year-end shoutouts

- October: **first Web 2.0 Conference** — audience = **businesspeople and investors** (not just developers). Second bubble being primed.  
- Theme: **“the Web as Platform.”**  
- Year-end Read/Write Web highlights:  
  1. **Google** — IPO August; competing with Microsoft desktop-as-platform (“Anti-Web 2.0” contrast in period geek talk).  
  2. **Flickr** — “most buzz of all the social software apps on the Web today.”  
  3. **del.icio.us** — tags as recommendation engine for blogosphere; successful topic mapping.  
  4. **FeedBurner** — RSS stats for bloggers.  

### 3.8 Exhibit implications

| Keep | Avoid |
|------|-------|
| “Social software” | Modern “social media” as 2004 default label |
| MySpace mass king (~1M mid-year) | Thefacebook as mass social |
| Bloglines as hero RSS app | Google Reader in 2004 |
| IE ~95% honesty | Firefox as default shell |
| Flickr as buzz leader | Yahoo-owns-Flickr in 2004 |

## 4. First Web 2.0 Conference — detailed notes

**URL:** https://cybercultural.com/p/003-the-first-web-20-conference-2004/  
**Author:** Richard MacManus · Nov 8, 2023  

### 4.1 Timeline context

| When | What |
|------|------|
| Mar 2004 | MacManus interviews Marc Canter (MacroMind → Macromedia lineage; PeopleAggregator / “digital lifestyle aggregator”) |
| Interview traffic | Slashdot + Boing Boing front pages; first big traffic for RWW |
| Jul 2004 | Tim O’Reilly Oscon 2004 keynote (listened via IT Conversations podcast) |
| ~Jun 2004 | Web 2.0 Conference advertised for early October San Francisco |
| **Oct 2004** | First **Web 2.0 Conference** |

### 4.2 O’Reilly Oscon 2004 (pre-conference)

- Quote he repeated: William Gibson — *“The future is here, it’s just not evenly distributed yet.”*  
- Emphasized **network effects**; Amazon, Google, eBay already had large networks and “data lock-in” opportunities.  
- Even newly launched **Gmail** ripe for network effects.  
- Warning: “The real big issue about Gmail is who’s going to own that data.”  
- Challenge to developers: open source P2P apps — “Napsterize the address book and the calendar.”  
- **No mention of the term “Web 2.0”** during that Oscon keynote.  

### 4.3 Web 2.0 Conference tone shift

- Target audience: **businesspeople and investors**, not developers.  
- Theme: **“Web as Platform.”**  
- Speakers class: Marc Andreessen, Jeff Bezos, Silicon Valley VCs (overwhelmingly white/male noted).  
- Co-chair John Battelle: “architecture of participation” — building business by letting customers build your business (user-generated content → “collective intelligence”).  
- Tone flip from Oscon: network effects **embraced** for commercial ends, not challenged.  
- Possible catalyst: **Google IPO (August)** between Oscon and Web 2.0 Conf.  

### 4.4 Andreessen panel notes (period business mood)

- “The new lock-in is clearly **data**.”  
- Compared Amazon/Google/eBay data companies to Dot-Com **walled gardens** (AOL, CompuServe).  
- “**eBay envy**” — in 2004 eBay often seen as better business than Amazon + Google combined (period market-cap class: eBay ~$77B vs Amazon ~$18B + Google ~$23B narrative in the essay).  

### 4.5 Exhibit room copy kit (Web 2.0 Conference)

- Oct 2004 · San Francisco  
- O’Reilly Media / business-investor audience  
- Theme: **Web as Platform**  
- Keywords: network effects · architecture of participation · collective intelligence · data lock-in · second bubble priming  
- Not a developer-only hacker conference

### 5.2 Google official press extract (on-disk)

**File:** `docs/references/2004/wayback-extracts/gmail-googlepress-20040401.txt`  
**Title family:** “Google Gets the Message, Launches Gmail”  
**Date:** April 1, 2004 · Mountain View  

**Key lines gathered:**

- Testing a **preview release** of Gmail — free **search-based** webmail.  
- Storage framed as up to eight billion bits (~500,000 pages of email per user) **and** museum-standard **1,000 MB / 1 GB** class.  
- Inspiration: user complaining about filing/deleting under ~**4 MB** limits.  
- “20 percent time” project origin story.  
- Unlike other free webmail: never have to file or delete as primary workflow; always find the message.  
- **Key features (official framing):**  
  1. **Search** — Google search over every email; keywords / advanced search.  
  2. **Storage** — hold onto mail forever; **1,000 megabytes (1 gigabyte)** free — more than 100× most free webmail.  
  3. **Speed / conversations** — organize into meaningful **conversations** with replies in context.  
  4. Spam → “canned meat” joke in press tone.  
- Small number of preview users at launch.  
- Visit: gmail.google.com  

### 5.3 PBS / AP 20-year piece — additional color

**URL:** PBS NewsHour / Michael Liedtke AP  

- Google co-founders known for April Fools pranks → Gmail on Apr 1 was deliberately unbelievable.  
- After AP published, readers called to say AP had been **duped**.  
- Page demoed Gmail in **Internet Explorer** (period honesty: IE is the mass browser).  
- **No delete button** featured in main control window — storage + search remove the need.  
- Three S’s pitch: **storage, search, speed** (Marissa Mayer).  
- Shift away from storage scarcity / delete-as-default.  
- Invite scarcity became **social currency**.  
- Gmail as first building block of Google beyond search (Maps, Docs, YouTube, Chrome, Android come later — **boundary for other years**).
