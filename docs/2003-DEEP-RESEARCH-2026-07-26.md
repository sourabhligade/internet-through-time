## 0. Thesis (verified 2026-07-26)

**2003 is when social graphs, paid digital music, self-hosted blogs, and pro-blog economics become mainstream products — still pre–Web 2.0 brand, pre-Facebook, pre-Firefox 1.0.**

| Pillar | Visitor should feel |
|--------|---------------------|
| **Social ramps** | **Friendster** is the mass public graph year (~3M fall); **MySpace** launches as fun HTML-customizable copycat (Aug) — still small vs Friendster by Oct (~100k) |
| **Music goes legit** | **iTunes Music Store** Apr 28 — **99¢** songs, AAC+DRM, Mac-first then **Windows Oct**; legal path vs KaZaA; **25M songs sold** by Dec 15 |
| **Blog tools fork** | **WordPress 0.7** May 27 (b2/cafelog fork); MT still pro; **Blogger bought by Google** Feb |
| **Pro blogs** | **AdSense** self-serve Jun 18 (content-targeted ads since Mar) → Gawker-class pro blogs |
| **Pro network** | **LinkedIn** launches **May 5** (founded Dec 2002) — careers, not dating |
| **Flash peak** | Flash sites still “default cool” (BowieNet v3, FWA / tokyoplastic) vs standards blogs |
| **RSS readers** | Desktop NetNewsWire / FeedDemon + browser **Bloglines** mid-2003 |
| **Continuity** | XP + IE6 · Amazon smile · Google · Yahoo · KaZaA still wild · Wikipedia densify · Wired CSS world continues |

**Scale (Live Stats, June 2003):** **40,912,332** websites (+6% YoY) · **~778,555,680** users.

**Handoff from shipped 2002:** Always-on minority broadband · Friendster seed · KaZaA · TrackBack · Wired CSS · Phoenix 0.1 · Google News → densify into **mass Friendster + MySpace seed + Music Store + WP + LinkedIn + AdSense + Google-Blogger**.

**One-line hub chip:** *MySpace · iTunes Store · WordPress · LinkedIn · AdSense.*

## 3. Room-by-room build kit

### 3.1 MySpace (P0 signature)

| Spec | Detail |
|------|--------|
| Launch | **August 2003** — museum label: “Aug 2003”; footnote Aug 1 (wiki) vs Aug 15 (Angwin/Cybercultural narrative) |
| Pitch | “Meet your friends' friends” · online community · photos, journals, interests |
| Feel | HTML-custom profiles · backgrounds/fonts/GIFs (Geocities energy) · Tom as default friend · Invite · network map |
| Contrast | Friendster = real-name / slow / Fakester bans; MySpace = looser friending + view anyone |
| Scale honesty | By Oct still **~100k** vs Friendster **~3M** — MySpace is **seed**, not yet king |
| Assets | RECON logo/avatars until WA Tom/logo; ban modern blue MySpace redesign |
| Immersion | Profile theme theater · Top Friends list · comment wall (localStorage) — no real accounts |

### 3.2 iTunes Music Store (P0 signature)

| Spec | Detail |
|------|--------|
| Launch | **Apr 28 2003** · 99¢ · 200,000+ songs · major labels · AAC 128k · DRM / FairPlay era |
| Platform | **Mac first** · U.S. only · Windows path **Oct 2003** · international later (2004+) |
| Rights framing | Own-file (with DRM) not subscription; burn personal CDs; unlimited iPods; 3 computers (Mac launch) |
| Scale | 1M first week (secondary press); **25M by Dec 15**; catalog → **400k+** |
| Ban | Spotify-like unlimited streaming as default · free full-song host · modern Apple Music UI |
| Immersion | Browse genres · 99¢ buy theater · library list localStorage · no real audio files / payments |
| Continuity | iPod gen2 + library from 2002; Store is the **new** room |
