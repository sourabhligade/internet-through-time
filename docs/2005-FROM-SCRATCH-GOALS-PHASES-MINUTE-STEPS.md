# Part 3 — How leftover engines work (every 2× / extra)

Read this once. Every leftover dest below uses one of these machines.

## 3.1 2× leftover (`year-4x-flows.js`)

Markup on the dest page:

```html
<section data-4x-panel data-4x-kind="KIND" data-4x-min="2">
  <!-- kind pieces here -->
  <button type="button" data-4x-go="SUFFIX">Save</button>
  <p data-4x-status></p>
  <p data-4x-result hidden></p>
  <p data-4x-next hidden>Next → …</p>
</section>
```

Key becomes `itt05-SUFFIX`.

| Kind | Visitor must | Incomplete (never writes) | Complete payload |
|------|--------------|---------------------------|------------------|
| `query` | type ≥ `min` chars in `[data-4x-field]` then Save | empty / too short | `{ q, kind, flow, real, multiStep, year:"2005" }` |
| `checks` | tick **every** `[data-4x-req]` then Save | any box off | `{ checks, … }` |
| `hops` | click ≥ `min` `[data-4x-hop]` then Save | fewer hops | `{ hops:[…], … }` |
| `wait` | click `[data-4x-wait]`, let timer finish, then Save | skip / click Save early | `{ waited:true, … }` |
| `toggle` | `[data-4x-toggle=off]` then `=on`, then Save | only off, or only on | `{ toggled:true, … }` |

Reload: if the key exists, status says “Still open”, result paints, Next unhides.

## 3.2 Extra-minute cabinets (`year-extra-minute.js`)

Kinds already in the kit: `pick` · `seq` · `form` · `search` · `hold` · `burst` · `buffer` · `wizard`.

| Kind | Incomplete | Complete |
|------|------------|----------|
| `pick` | no pick / wrong pick | Start then correct pick |
| `seq` | skip a step / out of order | every step in order |
| `form` | empty required field | fill + submit |
| `search` | empty query | query + results click |
| `hold` | release early | hold for `hold_ms` |
| `wizard` | skip a pane | next through last pane |

`?test=1` Finish is allowed for e2e and still writes REAL. Start must fire first.

## 3.3 Gold / official leftovers (custom writers)

Not the 4× kit. Own boot in `js/immersion/year-2005-extras.js` (create on implement). Same contract: count ticks, refuse empty, `saveJSON(key, blob)`, restore on load.
