## 2. Global goals

### 2.1 Visitor outcome

After gold, the visitor can do **one more year-true thing** that feels like that year — not a quiz about that year.

```
1. Finish ★ gold
2. See one “also this year” door (chip / pack / this dest)
3. Do the period verb (click banner, drop pegman, black page, uninstall Flash)
4. Incomplete path wrote nothing
5. Complete wrote ittYY-<leftover> only
6. Next is live, not the star (unless last leftover)
7. Guided still 6
```

1. Dest in the master table exists.  
2. Verb is a **product action**, not “tick I understand 2007.”  
3. Trap exists and never writes.  
4. Key is leftover (never the gold key).  
5. Home or pack links the dest **below** the star.  
6. e2e row in §6 is green.  
7. Lean HTML count did not jump a band.

- Restar CSotD / SSL / Lucky / Safari / Like / Hangout / Vine / Stories / GDPR / Zoom.  
- Restore 2014 Ice Bucket / Heartbleed / WhatsApp $19B.
