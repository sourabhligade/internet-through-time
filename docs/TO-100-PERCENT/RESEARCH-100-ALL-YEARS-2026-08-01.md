# Research freeze → 100% — all years 1994–2011

**Date:** 2026-08-01 (refresh pass — hub through **2011**)  
**Purpose:** One **stable** research map so every year can be taken to the project’s definition of **100%** without inventing new scores each time.  
**Method:** Disk truth (`years/1994`…`2011`) · all `*-MUSEUM-GRADE.md` · goals/playbooks · CAPTURE logs · Live Stats / Pingdom dual scale for late years.  
**Rule:** **Never invent brand pixels.** Harvest WA / evolt / GUIdebook / WDM / Version Museum or log `[failed]` and keep RECON.

**Legal:** Educational reconstruction only. localStorage theater. No real App Store binaries, APKs, P2P files, map tiles, SMTP, or payments.

## 0. Fixed definition of 100% (do not redefine)

From [`README.md`](README.md) — five layers. A year is **100%** only when **all five** are true:

| Layer | Required |
|-------|----------|
| **A. Story ship** | Year thesis live; hard bans enforced; period voice on product rooms |
| **B. Densify** | Signature rooms multi-page; tour-critical pages not schematic stubs |
| **C. Pixels** | Signature logos/chrome from dated WA / evolt / GUIdebook **where harvest works** |
| **D. Provenance** | CAPTURE-LOG + ASSETS honest; RECON never claimed as WA |
| **E. Gates** | urlMap complete · authenticity · smoke · year e2e ≥4–6 specs |

### Fixed status labels (use these forever)

| Label | Meaning |
|-------|---------|
| **100% content** | A+B+D+E done; C either WA or **accepted-final failed** |
| **MVP** | A + core P0 rooms + gates for signatures; densify residual open |
| **Densify ship** | Beyond MVP densify; residual optional forever only |
| **Optional forever** | Pixel/OEM harvest that failed or is evolt chrome — **does not block 100% content** |
| **Open work** | Must implement to claim 100% content |

**Do not use freehand “~90% / ~75%” scores.** Only the labels above.
