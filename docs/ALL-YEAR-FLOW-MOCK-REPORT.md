# All-year flow mock report — 1994–2017

Generated by `scripts/audit-all-year-flows.js`. Static HTML + hook scan — not a Playwright run.

## How to read a grade

| Grade | Meaning | Mock? |
| --- | --- | --- |
| **REAL** | Named product hook. Empty never writes. Writes JSON `{real, multiStep}`. | No |
| **REAL+PLAQUE** | Product hook is on the page, plus a leftover `data-5x-save` checkbox. | Plaque is mock; hook is not |
| **LITERACY** | Thesis / dual-cite ticks. Museum reading, not a product. | No (allowed) |
| **LEFTOVER** | Year-true pack or 3× popular fill+go. Thin, gated, not the chip. | Thin, not dest-field |
| **PLAQUE** | `data-5x-req` + `data-5x-save` checkbox theater. | **Yes — mock** |
| **VISIT** | Official stop with no writer / empty `whenKey`. Walk, not a flow. | Not a flow |
| **MISSING** | Trail href file is gone. | Broken |

Star = one-thing chip. Official = the 10 `flowTrails` stops. 3× = leftover popular rooms (never the chip).

`scripts/audit-mock-flows.js` (1994–2009 dest-field factory) is clean: no dest-field / I-saw / href=# action.
What remains mock is the leftover **5× checkbox plaque** (`data-5x-save`) glued onto costume rooms — including some official-10 dests.
