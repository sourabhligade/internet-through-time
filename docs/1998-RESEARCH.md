## 0. One-line thesis

**1998 is the portal peak + the first crack of the open web:** Yahoo/Excite/Netcenter fight for “stickiness” on TV; Microsoft ships **Windows 98** with IE glued in; **Netscape open-sources** and is bought by **AOL**; **Google** goes from Stanford project to company (homepage is a blank search box — not yet “the web”); **Amazon** starts selling **music/CDs** and looks more like a store; personal web (GeoCities) is still huge; Flash/DHTML/CSS fights heat up for developers.

This year should feel **richer, louder, and more commercial** than 1997 — and introduce **Google** as a quiet, almost academic newcomer, not the empire.

## 3. Browser & OS chrome (target feel)

### Recommendation: **Windows 98 + Internet Explorer 4.0 / early IE5 beta era**

| Layer | Spec |
|-------|------|
| OS | **Windows 98** — Start bar, system tray, slightly denser than Win95; teal/gray desktop optional |
| Browser default | **IE 4.01 / 5.0 beta** look — blue `e` throbber, Address bar + Go, Favorites, History |

| Modem default | **56k** (faster than 1997’s “new 56k” story — now assumed) |
| Address label | `Address:` (IE) not `Netsite:` |
| Favorites | Not Bookmarks as primary word |
| Channels / Active Desktop | Residual push tech; less central than 1997 PointCast peak |

**Sources:** GUIdebook Win98 (when available); WDM software IE; Cybercultural browser war notes; evolt IE4/IE5 builds.

## 12. Accuracy pitfalls (print next to keyboard)

1. **Google is tiny and new** — not the homepage of the internet yet.  
2. **Portals are the stars** — Yahoo/Excite/Netcenter TV-era arrogance.  
3. **Amazon sells music in 1998** — not “everything store” yet, not smile logo.  
4. **Windows 98**, not still pure Win95 (1997 room can stay Win95).  
5. **Netscape isn’t dead** — wounded, open source, then AOL.  
6. **Napster ≠ 1998 product** — 1999.  
7. Prefer **Wayback 1998** over inventing neon portals.
