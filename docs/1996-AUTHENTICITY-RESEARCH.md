## 3. Site authenticity briefs (P0)

### HoTMaiL (July 4, 1996)
- Spelling: **HoTMaiL** (HTML homage) — not Outlook, not modern Hotmail logo  
- Founders: Sabeer Bhatia + Jack Smith; free webmail = freedom from ISP-bound mail  
- UX: login → inbox table (From / Subject / Date) → compose  
- Visual: utilitarian blue/gray form-heavy pages, not Gmail  
- Storage theater: 2 MB era lore can appear as footer copy  
- Viral footer “Get your free email at HoTMaiL” (period growth hack) optional on compose footer  

**Exhibit flow:** register theater → inbox seed messages → compose saves to localStorage → sent folder  

### Space Jam (Nov 1996)
- Live reference: planet image-map hub, dark space bg, heavy GIFs  
- Sections: Jam Central, Junior Jam, Press Box, Lineup, Stellar Souvenirs, etc.  
- Grammar: image maps, table layout, Easter eggs, screen-saver downloads (fake)  
- **Trademark:** educational reconstruction; credit Warner Bros. / Space Jam  

### Yahoo! portal 1996
- Post-IPO denser home: more categories, Random, ads strip, search coexists with directory  
- Yellow/purple brand cues from WDM/Version Museum  
- Stickiness language (“start here”) without full My Yahoo personalization (tease only)  

### Excite (P1, high story value)
- April 1996 IPO alongside Yahoo & Lycos  
- Portal packaging around search; “land grab / stickiness” narrative (Cybercultural / Bell quotes)  
- Differentiator vs Yahoo: search-first portal skin  

### Amazon 1996
- Still books-first; **1.1M titles** narrative (WSJ / Bezos profile)  
- Recommendations strip (“customers who bought…”)  
- Associates program footnote  
- River-A logo — **no smile mark**  

### AuctionWeb
- **Still AuctionWeb** through 1996; rename eBay = **Sep 1997**  
- More categories / denser listings than 1995  

### GeoCities 1996
- Homesteader boom; neighborhoods expanded  
- Intermediate chaos: counters, webrings, awards — **not** peak 1998 glitter  
- Optional: homestead wizard (from realism research) fits this year best  

### AltaVista
- Still full-text king; cleaner results UI evolution from late-1995 launch

## 4. Browser chrome authenticity

### Netscape Navigator 3.0 (primary)
- Win95 desktop continuity  
- Richer Directory / Net Search / Net Directory  
- Plug-in status messaging  
- Standard vs **Gold** edition (mail + Composer) — About copy or thin mail window  
- Throbber N; multimedia browser marketing  

### Internet Explorer 3.0 (Aug 13, 1996)
- First IE that “catches up” in press (CNET era)  
- Optional dual-chrome toggle for browser-wars education  
- Do **not** default to IE majority — NN still leader late 1996  

### Modem
- Default **28.8**; optional **33.6** late year  
- **56k not normal** until ~1997

## 5. Tech that exists but must not dominate

| Tech | When | Museum rule |
|------|------|-------------|

| JS | Normal | Rollovers, status ticker, form check only |
