## Famous-that-year filter (how a dest gets YES)

A dest is **YES** only with a same-year primary or a dual-cite already frozen in repo READ-FIRST / research:

- **Visits chart that year** (Hosting.com / Media Metrix / PC Data / comScore) — AOL / Yahoo / MSN / eBay / Amazon / Google / MySpace.
- **Launch or acquire that year** with a contemporaneous press/blog cite already in repo (Napster 1999, Wikipedia 2001, thefacebook / Gmail / Firefox 2004, YouTube / Maps / Reddit 2005).
- **Cultural event that year** (Y2K, Pets.com crash, Napster shutdown, GeoCities Yahoo buy, Google IPO, News Corp → MySpace).

**MAYBE** = real  year product but niche (Everything2, Piczo, Tagged, yelplocal). Not leftover-3× B/C. Stay leftover-2×.

**NO** = anachronism or later-era fame parked early (YouTube on 1999, Facebook open / News Feed on 2004–05 gold path, Chrome, iPhone, Twitter, Google-owns-YouTube on 2005).
