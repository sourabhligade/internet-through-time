## How every year works (read once)

```
Hub  index.html
  └─ year card 1994–2018
        └─ years/YYYY/  (fake OS + period browser)
              iframe #content → pages/home.html   Starting Point
```

On Starting Point you always see:

1. **★ One-thing chip** — the star. Never moves when leftover is added.
2. **Guided 6** — About → star → two leftovers → map. Exactly six `<li>`.
3. **Official 10** — injected `Year flows 1–10` strip on every product room.
4. **Leftover 3×** — below the banner. Popular sites. Not the chip.
5. **Year game** — yellow box → `sites/playable/game.html`.

### Next vs Back (the mid-trail rule)

| Control | When it shows | Where it goes |
|---------|---------------|---------------|
| **Crumb `← last dest`** | Always, the moment you land | Previous official (or leftover) dest |
| **`[data-prev-flow]`** | Always (no longer hidden until you finish) | Same previous dest |
| **`Next:` chip** | Only after this dest writes its key | Next dest on that trail |
| **Starting Point** | Always | Lobby. Does **not** erase the trail. |
| **Chrome Back** | Browser iframe history | Whatever you actually opened |
| **Year flows 1–10 strip** | Always | Jump any official dest without completing |

Incomplete never writes. Empty field / missing pick / missing honesty tick never writes. Accept All never writes `itt18-gdpr`.

## Chassis — three trails, one year

```
Starting Point
 ├─ Guided 6 …………… first-night tour (visit mode, Continue always works)
 ├─ Official 10 ……… the year story. Next gated on whenKey
 ├─ Leftover 3× ……… popular leftover. Next gated on ittYY-pop-<slug>
 └─ Side leftovers … AirPods / Dyn / Animoji / archive / Manage replay
                     finish them → Next dumps you back on the official trail
```

You can hop between trails. The star does not change.

## What “broken in between” was

On dest 2–10 the only crumb was **Starting Point**. The `← last dest` link lived on `[data-prev-flow]` and stayed **hidden until you finished the current verb**. Finish Stories, Next to GO, land on GO, no way back except the lobby. That is the mid-trail dump.

**Now:** crumb always has `← last dest`. Prev is visible on land. Next still waits for the write. Side leftovers (AirPods / Dyn / Animoji) Next you **back onto the official trail**, not into a dead room.
