# 4. Shared leftover contract (minute markup)

Every dest you touch gets **exactly** this shape (adapt selectors):

```html
<html lang="en" data-itt-year="YYYY">
…
<p class="itt-pixel-failed">[failed-final] …</p>
<label><input type="checkbox" data-XX-req> honesty A</label>
<label><input type="checkbox" data-XX-req> honesty B</label>
<!-- optional picks -->
<button type="button" data-XX-pick="saveid">leftover save pick</button>
<button type="button" data-XX-pick="trapid">trap pick</button>
<!-- optional field -->
<input data-XX-field placeholder="…" maxlength="80">
<button type="button" data-XX-trap>Trap label</button>
<button type="button" data-XX-save>Save leftover</button>
<p data-XX-status></p>
<p hidden data-next-flow data-next-when-key="ittYY-suffix"><b>Next:</b> <a href="…">next official dest</a></p>
```

**Machine**

1. Trap click → status error · **no write**.  
2. Save with 0 ticks → no write.  
3. Save with ticks but no pick / field `< 2` / wrong pick → no write.  
4. Complete → `saveJSON(key("suffix"), blob({…}))` · reveal Next.  
5. Reload with saved.real → restore pick/field · Next visible.

**e2e (every dest)**

```
goto dest
removeItem(key); reload
click trap                         → key empty
click save                         → key empty
tick both; click save              → key empty   (if pick/field required)
wrong pick + save                  → key empty
right pick + field≥2 + save        → key JSON.real === true
  && year === "YYYY"
  && no itt(prev) / itt(next)
Next visible; href is the trail nextHref
```

**Payload minimum:** `{ real:true, multiStep:true, year:"YYYY", ts }` plus the dest’s fact (`pick`, `q`, `date`).
